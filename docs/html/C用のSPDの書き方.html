C用のSPDの書き方

C 言語のプログラムを SPD（Structured Programming Diagram）で設計するための入門書です。 規約（C/GitHub-Copilot/copilot-instructions.md）のうち、初めて書くときに知っておきたいことだけを選んで説明します。 細かい規則や例外は省いていますので、迷ったときは規約を参照してください。

各節では、SPD の例と、そこから生成される C のコードを対にして示します。

第1章 SPDの基本

1.1 SPDとは

SPD は、プログラムの処理の流れを、罫線で描いた木の形で表す設計図です。 順次・分岐・繰り返しを記号で表し、それぞれの処理は日本語で書きます。 SPD はコードを書くためだけでなく、アルゴリズムを考える練習にも使います。

配列の要素を集計する
  │
  ├─整数の配列を作成して、変数array に代入する
  │        └─array ← {10, 20, 30}
  ├─合計を入れる変数int total を宣言してゼロを代入する
  ├─↻─for: ループ変数をi としてarray の要素の数だけ繰り返す
  │  └─array[i]をtotal に加算する
  └─合計を "合計=〇〇" の書式でコンソールに表示する

int main(void) {
    int array[] = {10, 20, 30};

    int total = 0;

    for (int i = 0; i < ARRAY_LEN(array); i++) {
        total += array[i];
    }

    printf("合計=%d\n", total);

    wait_enter();
    return 0;
}
  • 1行目はタイトルです。プログラム名や処理の概要を書きます。
  • 関数として書いていない SPD は、main 関数の中身になります。
  • SPD に書いていない関数分割は行われません。 同じ処理が何度出てきても、関数にしたいときは自分で 関数: の SPD を書きます。

1.2 木の書き方

記号 意味
│ 処理の流れ（縦の線）
├─ 項目。同じ高さにまだ続きがある
└─ 最後の項目。または、上の項目の詳しい説明
  • 字下げが深い項目は、すぐ上の親の項目に属します。
  • └─ の子は、親の処理を詳しく説明したものとして読まれます。上の例の array ← {10, 20, 30} は、「整数の配列を作成して」の中身です。
  • 制御構造の記号は ◇（分岐）と ↻（繰り返し）の2つです。C の SPD では、例外処理の記号 〇 は使いません。
  • 罫線の前後の空白の揺れ（全角・半角の混在など）は気にしなくて構いません。

1.3 コメント

※ からその行末まではコメントです。処理としては読まれず、コードの同じ位置に // のコメントとして写されます。

├─変数int priceにキーボードから価格を入力する ※税抜き価格
│　※ここからは税込み価格の計算と表示
└─priceに1.1を掛けて四捨五入し、"税込=〇〇"の形式で表示する

int price = getInt(NULL);  // 税抜き価格
// ここからは税込み価格の計算と表示
printf("税込=%.0f\n", round(price * 1.1));
  • 引用符（"…"）や鉤括弧（「…」）の中の ※ は、コメントになりません。
  • 行の1文字目に ※ がある行（字下げしていない行）は、木の外の説明とみなされ、コードには写されません。

1.4 SPDはコードの先頭に残る

生成されるコードには、SPD 全体がブロックコメント（/* … */）としてそのまま残ります。 置かれる場所は、ファイルの先頭（#include より前）の1か所です。

/*
配列の要素を集計する
  │
  ├─整数の配列を作成して、変数array に代入する
  …
*/

#include <stdio.h>
#include "utils.h"

#define ARRAY_LEN(array) (sizeof(array) / sizeof((array)[0]))

int main(void) {
    …
}
  • main 用と関数用など複数の SPD があっても、分けずに1つのブロックにまとめて置かれます。コードからコピーして、SPD エディタに戻せます。

1.5 自動で補われるもの

次のものは、SPD に書かなくても自動で補われます。

補われるもの 補われるとき
#include <stdio.h> など 使う関数に合わせて
#define ARRAY_LEN(array) … 配列の要素数を使うとき
int main(void) と return 0; いつも
#include <stdbool.h> bool・true・false を使うとき
#include "input.h" キーボードから入力するとき
#include "utils.h" と、main の最後の wait_enter(); 画面に表示するとき（コンソールが閉じないようにするため）
関数のプロトタイプ宣言と、関数の直前の1行コメント 関数を作るとき

1.6 書きかけの部分はコードにならない

★ を含む行や、中身の無い 処理 がある関数は、書きかけとみなされ、コードが作られません。 推測で補われることはなく、代わりにコメント1行が置かれます。

関数: calcScore
  ├─目的：点数を計算する
  ├─引数
  │    └─int hand[]: 手札
  ├─戻り値
  │    └─int: 点数
  └─処理
        └─★ここにSPDを書く★

// calcScore関数：SPDが未記入のため生成していません
  • 書きかけかどうかは、関数の単位ごとに決まります。ほかの部分は、ふつうに生成されます。
  • 引数：なし・戻り値：なし のように なし と書いた項目は、書き終えたものとして扱われます。

第2章 順に実行する処理

2.1 変数と配列

変数は 変数<型> <名前> の形で書くと、その型で宣言されます。型を省略すると、C として自然な型が選ばれます。

├─合計を入れる変数int total を宣言してゼロを代入する
├─整数の配列を作成して、変数array に代入する
│        └─array ← {10, 20, 30}
└─行データを入れる変数line char[1000] を宣言する

int total = 0;
int array[] = {10, 20, 30};
char line[1000];
  • 代入は ← で書いても構いません（array ← {10, 20, 30}）。
  • 文字列は、決まった長さの char の配列で扱います。
  • 「リスト」ではなく「配列」と書きます。
  • 配列の要素数は、ARRAY_LEN(配列) で求められます。

2.2 キーボードからの入力

キーボードからの入力は、授業用の input.h の関数で行います（scanf は使いません）。

├─変数int ageにキーボードから年齢を入力する
├─変数double heightに身長を入力する（入力プロンプトは "身長>"）
└─名前を入れる変数name char[100] に、キーボードから文字列を入力する

int age = getInt(NULL);
double height = getDouble("身長>");
char name[100];
getString(name, sizeof(name), NULL);
入力するもの 使われる関数
整数 getInt(プロンプト)
実数 getDouble(プロンプト)
文字列 getString(配列, サイズ, プロンプト)
整数の配列（まとめて） getIntArray(配列, 要素数, プロンプト)
座標（x, y） getCoordinate(&x, &y, プロンプト)
  • 入力プロンプトを書くと、関数の引数になります。書かなければ NULL（標準のプロンプト）になります。
  • 入力の前に printf で案内を出す必要はありません。入力のエラー処理も要りません。

2.3 表示

├─合計を "合計=〇〇" の書式でコンソールに表示する
└─平均を "平均=〇〇.〇" の書式で小数点以下１桁まで表示する

printf("合計=%d\n", total);
printf("平均=%.1f\n", average);
  • "〇〇=△△" のように書式を示すと、その形で printf されます。〇〇 の部分に値が入ります。

2.4 計算と四捨五入

SPD の書き方 生成されるコード
平方根を計算する sqrt(x)
整数に四捨五入する round(x)
小数点以下2桁までに四捨五入する round(x * 100) / 100
doubleに変換する (double)value 
├─平均を計算して変数double averageに代入する
│    └─total をdoubleに変換し、配列array の要素数で割る

double average = (double)total / ARRAY_LEN(array);
  • sqrt・round を使うと、#include <math.h> が補われます。

第3章 分岐

3.1 if と else

分岐は ◇─条件 と書き、その下に条件が成り立つときの処理を書きます。成り立たないときの処理は └─else の下に書きます。

├─◇─scoreは60以上である
│  │    └─"合格"と表示する
│  └─else
│        └─"不合格"と表示する

if (score >= 60) {
    printf("合格\n");
} else {
    printf("不合格\n");
}

else が要らなければ、省きます。

3.2 独立した if と else if の見分け方

◇ の左にある最初の文字で、新しい if か、上の ◇ に続く else if かが決まります。ここはとても大事です。

◇ の左の最初の文字（空白は飛ばす） 意味
│、または行頭 上の ◇ の続き → else if
─（├─◇・└─◇） 新しい分岐 → 独立した if

else if にするとき（2つ目の ◇ の左は │）

├─◇─scoreは80以上である
│  │    └─"A"と表示する
│  ◇─scoreは60以上である
│  │    └─"B"と表示する
│  └─else
│        └─"C"と表示する

if (score >= 80) {
    printf("A\n");
} else if (score >= 60) {
    printf("B\n");
} else {
    printf("C\n");
}

独立した if を並べるとき（どちらの ◇ も左は ─）

├─◇─scoreは80以上である
│        └─"よくできました"と表示する
├─◇─absenceは3以上である
│        └─"補習があります"と表示する

if (score >= 80) {
    printf("よくできました\n");
}
if (absence >= 3) {
    printf("補習があります\n");
}
  • 字下げの位置が同じでも、意味は違います。 見るのは ◇ の左の文字だけです。

3.3 switch

1つの値で場合分けするときは、◇─switch: と書き、子に case を並べます。

├─◇─switch: rankの値で判定
│  ├─case 1→ "優"と表示する
│  ├─case 2, 3 → "良"と表示する
│  └─それ以外→"可"と表示する

switch (rank) {
    case 1:
        printf("優\n");
        break;
    case 2:
    case 3:
        printf("良\n");
        break;
    default:
        printf("可\n");
        break;
}
  • 各 case の最後には break; が自動で付きます。

第4章 繰り返し

繰り返しは ↻─ で表します。繰り返す処理は、その子に書きます。

4.1 配列の要素を順に処理する

└─↻─for: ループ変数をi として、array の要素の数だけ繰り返す
    └─array[i]を表示する

for (int i = 0; i < ARRAY_LEN(array); i++) {
    printf("%d\n", array[i]);
}

4.2 回数を数えて繰り返す

└─↻─for: i を0 からn 未満まで1 ずつ増やす
    └─iを表示する

for (int i = 0; i < n; i++) {
    printf("%d\n", i);
}

4.3 条件が成り立つ間繰り返す

└─↻─while: number にキーボードから整数を入力し、それが0 でない間繰り返す
    └─numberをtotalに加算する

while ((number = getInt(NULL)) != 0) {
    total += number;
}

途中で抜けるときは、while: true と break を組み合わせます。

├─↻─while: true
│     ├─変数int nにキーボードから整数を入力する
│     ├─◇─nは0である
│     │        └─breakでループを脱出する
│     └─nをtotalに加算する

while (true) {
    int n = getInt(NULL);
    if (n == 0) {
        break;
    }
    total += n;
}

第5章 ファイルとエラーへの備え

5.1 エラーは分岐で書く

C には例外処理がありません。失敗するかもしれない処理は、◇ の分岐で失敗したときの処理を書きます。

├─fruit.txt を読み込み用に開き、変数fileに代入する
├─◇─file はNULLである
│        └─"ファイル入力エラー" を表示して1 を返して終了する

FILE *file = fopen("fruit.txt", "r");
if (file == NULL) {
    fprintf(stderr, "ファイル入力エラー\n");
    return 1;
}
  • エラーのメッセージは、fprintf(stderr, …) で表示されます。

5.2 ファイルを読む

行単位のファイル読み込み
  │
  ├─fruit.txt を読み込み用に開き、変数fileに代入する
  ├─◇─file はNULLである
  │        └─"ファイル入力エラー" を表示して1 を返して終了する
  ├─行データを入れる変数line char[1000] を宣言する
  ├─↻─while: fileから1 行分をlineに読み込み、成功している間繰り返す
  │  └─line をコンソールに表示する
  └─file を閉じる

int main(void) {
    FILE *file = fopen("fruit.txt", "r");
    if (file == NULL) {
        fprintf(stderr, "ファイル入力エラー\n");
        return 1;
    }

    char line[1000];
    while (fgets(line, sizeof(line), file) != NULL) {
        printf("%s", line);
    }

    fclose(file);

    wait_enter();
    return 0;
}
SPD の書き方 生成されるコード
読み込み用に開く fopen("…", "r")
1行分をlineに読み込む fgets(line, sizeof(line), file)
ファイルへ書き込む fprintf(file, …)
閉じる fclose(file)
  • 開いたファイルは、必ず「閉じる」まで書きます。

第6章 関数

6.1 関数の形

関数は、タイトルを 関数: <名前> とし、子に 目的・引数・戻り値・処理 を書きます。

関数: average
  ├─目的：配列の平均を求める
  ├─引数
  │    ├─const int data[]: 値の配列
  │    └─int count: 要素数
  ├─戻り値
  │    └─double: 平均
  └─処理
        ├─合計を入れる変数int total を宣言してゼロを代入する
        ├─↻─for: i を0 からcount 未満まで1 ずつ増やす
        │    └─data[i]をtotal に加算する
        └─total をdoubleに変換し、count で割った値を返す

double average(const int data[], int count);

// 配列の平均を求める
double average(const int data[], int count) {
    int total = 0;
    for (int i = 0; i < count; i++) {
        total += data[i];
    }
    return (double)total / count;
}
  • プロトタイプ宣言（関数の形だけを先に示す宣言）が、自動で作られます。
  • 目的 が、関数の直前の1行コメントになります。
  • 値を返すときは、処理 に 〜を返す と書きます。

6.2 引数と戻り値の書き方

項目 書き方 例
引数 <型> <名前>: <説明>（型が先） int count: 要素数
引数が1つ 引数 に続けて1行で書ける 引数：Card card: 対象のカード
引数が無い 引数：なし
戻り値 <型>: <説明>（型が先） double: 平均
戻り値が無い 戻り値：なし
  • 引数も戻り値も、型を先に書きます。 平均: double のように逆にすると読めません。
  • 1行に書ける引数は1つだけです。2つ以上は、子の行に分けます。

6.3 ファイル内専用の関数（static）

関数名の前に static を付けると、そのファイルの中だけで使う関数になります。

関数: static textureIndex
  ├─目的：Card からテクスチャ配列 cardTextures の添字を求める
  ├─引数
  │    └─Card card: 対象のカード（suit: 0〜3、rank: 1〜13）
  ├─戻り値
  │    └─int: 配列の添字（0〜51）
  └─処理
        └─suit × 13 + (rank − 1) を返す

static int textureIndex(Card card);

// Card からテクスチャ配列 cardTextures の添字を求める
static int textureIndex(Card card) {
    return card.suit * 13 + (card.rank - 1);
}

第7章 構造体・列挙型・グローバル変数

7.1 構造体

いつも一緒に扱う複数の値は、構造体にまとめます。タイトルを 構造体: <名前> とし、メンバーを <説明>: <型> <名前> で並べます。

構造体: product
  │
  ├─型番: char number[20]
  ├─品名: char name[100]
  ├─価格: int price
  └─在庫の有無: bool stock

typedef struct {
    char number[20];
    char name[100];
    int price;
    bool stock;
} Product;
  • 型の名前は、先頭が大文字（Product）になります。
  • 文字列のメンバーは、決まった長さの char の配列にします。

7.2 列挙型

決まった値のどれかをとる型は、列挙型にします。タイトルを 列挙型: <名前> とし、値を <説明>: <名前> で並べます。

列挙型: suit
  │
  ├─クラブ: CLUB
  ├─ダイア: DIAMOND
  ├─ハート: HEART
  └─スペード: SPADE

typedef enum {
    CLUB,
    DIAMOND,
    HEART,
    SPADE
} Suit;

7.3 グローバル変数

関数の外に置く変数は、タイトルを グローバル変数 とし、1行に1つずつ C の宣言と同じ形で書きます。

グローバル変数
  │
  ├─static Texture2D cardTextures[DECK_SIZE] ※52枚分のカードテクスチャ
  └─int totalScore ←0

// 52枚分のカードテクスチャ
static Texture2D cardTextures[DECK_SIZE];
int totalScore = 0;
  • 初期値は ← で書きます。書かなければ、初期値は付きません。
  • static は、書いたときだけ付きます（ファイル内専用になります）。

7.4 複数のファイルに分けるとき

ゲームのように、プログラムを複数の .c と .h に分けるときも、SPD に #include を書く必要はありません。

  • 各ファイルの #include は、そのファイルで使っているものだけが自動で選ばれます。
  • ヘッダファイル（.h）の構造体・列挙型・#define は、SPD に書いたとおりに作られます。
  • ヘッダのプロトタイプ宣言は、対応する .c の関数（static でないもの）から自動で作られます。
  • ファイル同士が互いを必要とする形（循環）にならないよう、下の層から順に設計します（例：card → hand・deck → game）。

第8章 まとめ

8.1 完全な例

配列の要素を集計する
  │
  ├─整数の配列を作成して、変数array に代入する
  │        └─array ← {10, 20, 30}
  ├─合計を入れる変数int total を宣言してゼロを代入する
  │
  ├─↻─for: ループ変数をi としてarray の要素の数だけ繰り返す
  │  └─array[i]をtotal に加算する
  │
  ├─平均を計算して変数double averageに代入する
  │    └─total をdoubleに変換し、配列array の要素数で割る
  │
  ├─合計を "合計=〇〇" の書式でコンソールに表示する
  └─平均を "平均=〇〇.〇" の書式で小数点以下１桁まで表示する

/*
（SPD 全体）
*/

#include <stdio.h>
#include "utils.h"

#define ARRAY_LEN(array) (sizeof(array) / sizeof((array)[0]))

int main(void) {
    int array[] = {10, 20, 30};

    int total = 0;

    // 配列の全要素を合計する
    for (int i = 0; i < ARRAY_LEN(array); i++) {
        total += array[i];
    }

    double average = (double)total / ARRAY_LEN(array);

    printf("合計=%d\n", total);
    printf("平均=%.1f\n", average);

    wait_enter();
    return 0;
}

8.2 よくある間違い

間違い 正しい書き方 理由
else if のつもりで ├─◇─ を続けて書く 2つ目を │ ◇─ と書く ◇ の左が ─ だと独立した if になる
〇─try でエラーを処理する ◇─file はNULLである のように分岐で書く C の SPD では 〇 を使わない
引数を 要素数: int count と書く int count: 要素数 引数は型が先
戻り値を 平均: double と書く double: 平均 戻り値も型が先
同じ処理を関数にしてくれると期待する 関数: の SPD を書く SPD に無い関数分割は行われない
リストを作る と書く 配列を作る と書く C では配列を使う
ファイルを開いたまま終える 最後に file を閉じる を書く 開いたファイルは閉じる
処理 に ★ここに書く★ を残す 処理を書く 書きかけとみなされ、コードが作られない
