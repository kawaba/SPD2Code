第1章 SPDの基本

1.1 SPDとは

SPD は、プログラムの処理の流れを、罫線で描いた木の形で表す設計図です。 順次・分岐・繰り返し・例外処理を記号で表し、それぞれの処理は日本語で書きます。

リストの要素を集計する
│
├─整数のリストを作成して、変数scoresに代入する
│        └─要素は(10, 20, 30)
├─合計を入れる変数totalを宣言してゼロを代入する
├─↻─for: score ← scores
│        └─scoreをtotalに加算する
└─合計を"合計＝〇〇"の書式で表示する

scores = [10, 20, 30]

total = 0
for score in scores:
    total += score

print(f"合計＝{total}")
  • 1行目はタイトルです。プログラム名や処理の概要を書きます。
  • 関数やクラスの定義が無い SPD は、ファイルの一番外側（トップレベル）にそのまま書かれるコードになります。 main() 関数は、SPD に書いたときだけ作られます（6.3）。
  • 1つの SPD は、原則として1つのプログラム・1つの関数・1つのクラスに対応します。

1.2 木の書き方

記号 意味
│ 処理の流れ（縦の線）
├─ 項目。同じ高さにまだ続きがある
└─ 最後の項目。または、上の項目の詳しい説明
  • 字下げが深い項目は、すぐ上の親の項目に属します。
  • └─ の子は、親の処理を詳しく説明したものとして読まれます。上の例の 要素は(10, 20, 30) は、「整数のリストを作成して」の中身です。
  • 制御構造の記号（◇・↻・〇）は、第3章から説明します。
  • 罫線の前後の空白の揺れ（全角・半角の混在など）は気にしなくて構いません。

1.3 コメント

※ からその行末まではコメントです。処理としては読まれず、コードの同じ位置に # のコメントとして写されます。

├─変数priceにキーボードから価格を入力する ※税抜き価格
│　※ここからは税込み価格の計算と表示
└─priceに1.1を掛けて整数に丸め、"税込=〇〇"の形式で表示する

price = int(input("価格> "))  # 税抜き価格
# ここからは税込み価格の計算と表示
print(f"税込={round(price * 1.1)}")
  • 引用符（"…"）や鉤括弧（「…」）の中の ※ は、コメントになりません。
  • 行の1文字目に ※ がある行（字下げしていない行）は、木の外の説明とみなされ、コードには写されません。

1.4 SPDはファイルの先頭に置く

SPD は、Python ファイルの先頭の """ で囲んだブロックに書きます。コードは、その下に作られます。

"""
関数: score
  │
  ├─目的：3科目のテストの合計と平均を計算する
  …
"""


def score(math, science, english):
    """3科目のテストの合計と平均を計算します。"""
    …
  • SPD のブロックは、そのまま残ります。 コードを作り直しても書き換えられません。
  • 関数用・クラス用など複数の SPD があっても、先頭の1つのブロックにまとめて書きます。
  • 関数やクラスの docstring には、SPD の 目的 だけが短く書かれます。
  • import 文は自動で補われるので、SPD に書く必要はありません。

1.5 書きかけの部分はコードにならない

★ を含む行や、中身の無い 処理 がある関数は、書きかけとみなされ、コードが作られません。 推測で補われることはなく、代わりに次のようなコメント1行が置かれます。

関数: calc_score
  ├─目的：点数を計算する
  ├─引数
  │    └─手札: hand
  ├─戻り値: 点数 -> int
  └─処理
        └─★ここにSPDを書く★

# calc_score関数：SPDが未記入のため生成していません
  • 書きかけかどうかは、関数やクラスの単位ごとに決まります。ほかの部分は、ふつうに生成されます。
  • 引数: なし・戻り値: なし・属性：なし のように なし と書いた項目は、書き終えたものとして扱われます。

第2章 順に実行する処理

2.1 変数と代入

変数の名前は、SPD に書いた名前がそのまま使われます。名前は英語のスネークケース（total_score など）にします。

├─合計を入れる変数totalを宣言してゼロを代入する
├─整数のリストを作成して、変数scoresに代入する
│        └─要素は(10, 20, 30)
└─km ← mile * 1.609

total = 0
scores = [10, 20, 30]
km = mile * 1.609
  • 代入は ← で書いても構いません（km ← mile * 1.609）。
  • int total のように型を添えても構いません。Python では型の説明として読まれ、コードには型は書かれません。
  • list・sum・str など Python の組み込みの名前は、変数名に使わないでください。 書いた場合は、numbers などの自然な名前に置き換えられます。

2.2 キーボードからの入力

キーボードからの入力は、標準の input() で行われます。数として使う値は、自動で int()・float() に変換されます。

├─変数ageにキーボードから年齢を整数で入力する
└─身長を変数heightに実数で入力する（入力プロンプトは "身長(cm)> "）

age = int(input("年齢> "))
height = float(input("身長(cm)> "))
  • 入力プロンプトを指定しなければ、"年齢> " のような短いプロンプトが自動で付きます。プロンプトには必ず > が入ります。
  • 授業用の tkxlib を使うときは、SPD に「tkxlibからget_intをインポートする」のように書きます。そのときだけ get_int() などが使われます。

2.3 表示

├─memberを表示する
└─合計を"合計＝〇〇"の書式で表示する

print(member)
print(f"合計＝{total}")
  • "〇〇=△△" のように書式を示すと、f 文字列で表示されます。〇〇 の部分に値が入ります。

2.4 四捨五入

SPD の書き方 生成されるコード
小数点以下2桁までに四捨五入する round(x, 2)
整数に丸める round(x)

第3章 分岐

3.1 if と else

分岐は ◇─条件 と書き、その下に条件が成り立つときの処理を書きます。成り立たないときの処理は └─else の下に書きます。

├─◇─scoreは60以上である
│  │    └─"合格"と表示する
│  └─else
│        └─"不合格"と表示する

if score >= 60:
    print("合格")
else:
    print("不合格")

else が要らなければ、省きます。

3.2 独立した if と elif の見分け方

◇ の左にある最初の文字で、新しい if か、上の ◇ に続く elif かが決まります。ここはとても大事です。

◇ の左の最初の文字（空白は飛ばす） 意味
│、または行頭 上の ◇ の続き → elif
─（├─◇・└─◇） 新しい分岐 → 独立した if

elif にするとき（2つ目の ◇ の左は │）

├─◇─scoreは80以上である
│  │    └─"A"と表示する
│  ◇─scoreは60以上である
│  │    └─"B"と表示する
│  └─else
│        └─"C"と表示する

if score >= 80:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")

独立した if を並べるとき（どちらの ◇ も左は ─）

├─◇─scoreは80以上である
│        └─"よくできました"と表示する
├─◇─absenceは3以上である
│        └─"補習があります"と表示する

if score >= 80:
    print("よくできました")
if absence >= 3:
    print("補習があります")
  • 字下げの位置が同じでも、意味は違います。 見るのは ◇ の左の文字だけです。

3.3 match

1つの値で場合分けするときは、◇─match: と書き、子に case を並べます。

└─◇─match: codeの値で判定
    ├─case 100なら「正常終了」と表示する
    ├─case 200か201なら「ページが存在しない」と表示する
    └─default それ以外は「内部エラー」と表示する

match code:
    case 100:
        print("正常終了")
    case 200 | 201:
        print("ページが存在しない")
    case _:
        print("内部エラー")

3.4 条件式

◇ を使わず、1行で「〜なら A を、それ以外なら B を代入する」と書くと、条件式になります。

├─numberが6なら"当たり"を、それ以外なら"はずれ"を変数messageに代入する

message = "当たり" if number == 6 else "はずれ"

第4章 繰り返し

繰り返しは ↻─ で表します。繰り返す処理は、その子に書きます。

4.1 リストの要素を順に処理する

↻─for: <変数> ← <リストなど> と書きます。← は「右のものから1つずつ取り出して左の変数に入れる」という意味です。

└─↻─for: name ← names
   └─nameを表示する

for name in names:
    print(name)
  • 回数を数えるときは、↻─for: i ← range(10) のように書けます。

4.2 条件が成り立つ間繰り返す

└─↻─while: numberが0でない間繰り返す
   └─処理

while number != 0:
    処理

途中で抜けるときは、while: True と break を組み合わせます。

├─↻─while: True
│     ├─変数numberにキーボードから整数を入力する
│     ├─◇─numberは0である
│     │        └─breakでループを脱出する
│     └─totalにnumberを加算する

while True:
    number = int(input("整数> "))
    if number == 0:
        break
    total += number

4.3 内包表記

「リスト内包表記で」と書いたときだけ、内包表記が作られます。子に for:・変換:・条件: の枝を書きます。

├─リスト内包表記で新しいリストnew_numbersを作成する
│      ├─for: num ← numbers
│      ├─変換: num * 2
│      └─条件: num % 2 == 0

new_numbers = [num * 2 for num in numbers if num % 2 == 0]
枝 意味 省略
for: 変数 ← リストなど 取り出す元 できない
変換: 式 各要素から作る値 できる（要素そのものになる）
条件: 式 残す要素の条件 できる（すべて残る）
  • for: には ↻ を付けません。
  • 辞書内包表記では、変換 の子に キー: 式 と 値: 式 を書きます。
├─辞書内包表記で、usersからuser_mapを作る
│      ├─for: user ← users
│      └─変換
│            ├─キー: user["name"]
│            └─値: user["id"]

user_map = {user["name"]: user["id"] for user in users}
  • 「内包表記で」と書かない繰り返しは、ふつうの for 文になります。

第5章 例外処理とファイル

5.1 try と except

例外処理は 〇─try: と 〇─except <例外クラス> as e: で表します。

└─〇─try:
    │   └─textを整数に変換して変数numberに代入する
    〇─except ValueError as e:
         └─"数字を入力してください"と表示する

try:
    number = int(text)
except ValueError as error:
    print("数字を入力してください")
  • 例外処理は、SPD に 〇 を書いたときだけ作られます。 ファイルを扱う処理でも、書かなければ作られません。
  • 例外クラスが複数あるときは、(OSError, UnicodeDecodeError) のように括弧で並べます。
  • 例外を発生させるときは、ValueError("年齢は0以上")を発生する のように書きます（raise になります）。

5.2 ファイルを読む

ファイルは pathlib.Path で扱い、文字コードは UTF-8 になります。with 文で開くときは、try: の右に書きます。

├─"data.txt"のパスを作って変数pathに代入する
└─〇─try: with文で、pathの入力用ファイルオブジェクトをfile_objにセットする
    │   └─↻─for: line ← file_obj
    │      └─lineを表示する
    〇─except (OSError, UnicodeDecodeError) as e:
          └─"ファイル入力エラー"と表示する

from pathlib import Path

path = Path("data.txt")
try:
    with path.open("r", encoding="utf-8") as file_obj:
        for line in file_obj:
            print(line, end="")
except (OSError, UnicodeDecodeError) as error:
    print("ファイル入力エラー")
  • CSV ファイルは、標準の csv モジュールで読み書きされます。

第6章 関数

6.1 関数の形

関数は、タイトルを 関数: <名前> とし、子に 目的・引数・戻り値・処理 を書きます。

関数: mile2km
  │
  ├─目的：マイルをキロメートルに変換する
  ├─引数
  │    └─マイルの値: mile: float
  │
  ├─戻り値: キロメートルの値 -> float
  │
  └─処理
        ├─km ← mile * 1.609
        ├─kmを小数点以下2桁までに四捨五入する
        └─kmを返す

def mile2km(mile):
    """マイルをキロメートルに変換します。"""
    km = mile * 1.609
    km = round(km, 2)
    return km
  • 目的 が docstring になります。
  • 値を返すときは、処理 に 〜を返す と書きます。
  • 通常の関数には、型ヒント（: float など）は付きません。型は説明として書いておけます。

6.2 引数と戻り値の書き方

項目 書き方 例
引数 <説明>: <名前>: <型>（型は省略できる） マイルの値: mile: float
戻り値 <説明> -> <型>（型は省略できる） 戻り値: キロメートルの値 -> float
引数・戻り値が無い 引数: なし・戻り値: なし
  • 型の印は、引数ではコロン（: 型）、戻り値では矢印（-> 型）です。Python の型ヒントと同じ向きです。
  • 説明と名前は、mile: マイルの値 のように逆の順でも構いません。
  • コロンは全角の ： でも半角の : でも構いません。

6.3 main 関数

関数: main の SPD を書いたときだけ、main() と実行の入口（if __name__ == "__main__":）が作られます。

関数: main
  │
  └─処理
        ├─数学・理科・英語の点数をキーボードから入力する
        ├─score()を呼び出して、戻り値を変数totalとaverageに代入する
        └─"合計=〇〇、平均=〇〇"の形式で表示する

def main():
    """3科目の点数から合計と平均を求めて表示します。"""
    math = int(input("数学> "))
    science = int(input("理科> "))
    english = int(input("英語> "))
    total, average = score(math, science, english)
    print(f"合計={total}、平均={average}")


if __name__ == "__main__":
    main()
  • 関数: main では、目的・引数・戻り値 を省略できます。ほかの関数では、無いときも 引数: なし のように書きます。
  • 関数: main が無ければ、処理はトップレベルにそのまま書かれます。

第7章 クラス

7.1 クラスの形

クラスは、タイトルを クラス: <名前> とし、属性・特殊メソッド・メソッド: などを枝として並べます。

クラス: Member
│
├─目的：会員を表すクラス
├─属性
│    ├─番号：uid: int
│    └─名前：name: str
│
├─特殊メソッド
│    ├─コンストラクタ
│    └─表示メソッド
│
└─メソッド: greet
     ├─目的: 挨拶を表示する
     ├─引数: なし
     ├─戻り値: なし
     └─処理
          └─"こんにちは、〇〇さん"の形式で名前を表示する

class Member:
    """会員を表すクラス。"""

    def __init__(self, uid: int, name: str) -> None:
        self.uid = uid
        self.name = name

    def __str__(self) -> str:
        return f"Member({self.uid}, {self.name})"

    def __repr__(self) -> str:
        return f"Member(uid={self.uid!r}, name={self.name!r})"

    def greet(self) -> None:
        """挨拶を表示します。"""
        print(f"こんにちは、{self.name}さん")
枝 書く内容
目的 クラスの説明（docstring になる）
属性 インスタンスの属性。<説明>: <名前>: <型>
特殊メソッド 自動で作る特殊メソッド（7.2）
メソッド: <名前> インスタンスメソッド
クラス変数・クラスメソッド:・スタティックメソッド: 7.4
  • クラスのメソッドには、型ヒントが必ず付きます。 属性・引数の : 型 と戻り値の -> 型 を書いておきます。
  • メソッドの 引数 に self は書きません。自動で補われます。
  • 行末の全角括弧 （…） は注記として読まれ、コードには影響しません。

7.2 特殊メソッド

特殊メソッド の枝に書けるのは、次の3つだけです。書いたものだけが作られます。

指定 作られるメソッド
コンストラクタ __init__（すべての属性を引数に取る）
表示メソッド __str__ と __repr__
等値メソッド __eq__ と __hash__
  • 等値メソッド <- uid のように、比べる属性を指定できます。指定しなければ、すべての属性で比べます。
  • 特殊メソッドが要らないときは、特殊メソッド：なし と書きます。

7.3 仮想属性（アンダースコア付きの属性）

属性の名前を _age のようにアンダースコアで始めると、仮想属性になり、読み出し用の @property が自動で作られます。

├─属性
│    └─年齢：_age: int
│
├─特殊メソッド
│    └─コンストラクタ
│
└─メソッド：age
     ├─目的：ageのセッター
     ├─引数
     │    └─年齢：age_value: int
     ├─戻り値：なし
     └─処理
           ├─◇─age_valueは負である
           │          └─ValueError("年齢は0以上")を発生する
           └─_ageにage_valueを代入する

    def __init__(self, age: int) -> None:
        self._age = age

    @property
    def age(self) -> int:
        """年齢を返します。"""
        return self._age

    @age.setter
    def age(self, age_value: int) -> None:
        if age_value < 0:
            raise ValueError("年齢は0以上")
        self._age = age_value
  • 書き込み用（セッター）は自動では作られません。属性と同じ名前の メソッド:（メソッド：age）を書くと、セッターになります。
  • コンストラクタの引数名には、アンダースコアが付きません（age）。

7.4 クラス変数・クラスメソッド・スタティックメソッド

├─クラス変数
│      └─会費: FEE: int = 5000
│
└─スタティックメソッド: with_tax
    ├─目的: 税抜き価格から税込み価格を計算して返す
    ├─引数
    │    └─税抜き価格: price: int
    ├─戻り値: 税込み価格 -> int
    └─処理
          └─priceに1.1を掛けて整数に丸めた値を返す

    FEE = 5000

    @staticmethod
    def with_tax(price: int) -> int:
        """税抜き価格から税込み価格を計算して返します。"""
        return round(price * 1.1)
枝 作られるもの
クラス変数 クラス直下の変数。<説明>: <名前>: <型> = <値> と書く
クラスメソッド: <名前> @classmethod。第1引数 cls が自動で付く
スタティックメソッド: <名前> @staticmethod。self も cls も付かない
  • クラスメソッドは、CSV の文字列からインスタンスを作る、といった用途に使います。中でインスタンスを作るときは cls(...) になります。

7.5 継承

タイトルのクラス名の右に、─⊳ と親クラスを書きます。

クラス: GeneralMember ─⊳ Member
│
├─目的：一般会員のクラス
├─属性
│    └─レッスンメニュー: lesson_menu: list[str]
│
└─特殊メソッド
      └─コンストラクタ

class GeneralMember(Member):
    """一般会員のクラス。"""

    def __init__(self, uid: int, name: str,
                 lesson_menu: list[str]) -> None:
        super().__init__(uid, name)
        self.lesson_menu = lesson_menu
  • コンストラクタは、親クラスの属性も引数に取り、super().__init__(...) を呼ぶ形で作られます。
  • 親クラスは、─⊳ JsonMixin、Member のように複数並べられます（ミックスイン）。書いた順に並びます。
  • Java の実装の記号 ---⊳ は、Python では使いません。

7.6 データクラス

値をまとめることが主な目的のクラスは、タイトルを データクラス: <名前> とします。@dataclass が付きます。

データクラス: Person
│
├─目的：個人を表すクラス
└─属性
     ├─氏名: name: str
     └─年齢: age: int

from dataclasses import dataclass


@dataclass(frozen=True)
class Person:
    """個人を表すクラス。"""

    name: str
    age: int
  • データクラスの属性には、型が必須です。
  • 値を後から変えないクラスには、frozen=True が付きます。
  • 値の検査は、メソッド: __post_init__ に書きます。

8.1 完全な例

"""
関数: score
  │
  ├─目的：3科目のテストの合計と平均を計算する
  ├─引数
  │    ├─math：数学のテストの点数
  │    ├─science：理科のテストの点数
  │    └─english：英語のテストの点数
  ├─戻り値─合計と平均のタプル
  └─処理
      ├─合計を計算して変数totalに代入する
      ├─平均を計算して小数点以下1桁までに丸めて、変数averageに代入する
      └─totalとaverageをタプルにして返す

関数: main
  │
  └─処理
        ├─数学・理科・英語の点数をキーボードから入力する
        ├─score()を呼び出して、戻り値を変数totalとaverageに代入する
        └─"合計=〇〇、平均=〇〇"の形式で表示する
"""

def score(math, science, english):
    """3科目のテストの合計と平均を計算します。"""
    total = math + science + english
    average = round(total / 3, 1)
    return total, average


def main():
    """3科目の点数から合計と平均を求めて表示します。"""
    math = int(input("数学> "))
    science = int(input("理科> "))
    english = int(input("英語> "))
    total, average = score(math, science, english)
    print(f"合計={total}、平均={average}")


if __name__ == "__main__":
    main()
