各節では、SPD の例と、そこから生成される Java のコードを対にして示します。

第1章 SPDの基本

1.1 SPDとは

SPD は、プログラムの処理の流れを、罫線で描いた木の形で表す設計図です。 順次・分岐・繰り返し・例外処理を記号で表し、それぞれの処理は日本語で書きます。

リストの要素を集計する
  │
  ├─整数のリストを作成して、変数listに代入する
  │    └─要素は(10, 20, 30)
  ├─合計を入れる変数int totalを宣言してゼロを代入する
  ├─↻─for:変数nにlistから毎回１つずつ要素を取り出す
  │       └─nをtotalに加算する
  └─合計を"合計＝〇〇"の書式でコンソールに表示する

public class ListAggregation {
    public static void main(String[] args) {
        var list = List.of(10, 20, 30);

        int total = 0;
        for (var n : list) {
            total += n;
        }

        System.out.printf("合計＝%d%n", total);
    }
}
  • 1行目はタイトルです。プログラム名や処理の概要を書きます。
  • タイトルだけで型（クラスなど）の宣言が無い SPD は、main メソッドの中身になります。
  • 1つの SPD は、原則として1つのプログラム・1つのメソッド・1つのクラスに対応します。

1.2 木の書き方

記号 意味
│ 処理の流れ（縦の線）
├─ 項目。同じ高さにまだ続きがある
└─ 最後の項目。または、上の項目の詳しい説明
  • 字下げが深い項目は、すぐ上の親の項目に属します。
  • └─ の子は、親の処理を詳しく説明したものとして読まれます。上の例の 要素は(10, 20, 30) は、「整数のリストを作成して」の中身です。
  • 制御構造の記号（◇・↻・〇 など）は、第3章から説明します。
  • 罫線の前後の空白の揺れ（全角・半角の混在など）は気にしなくて構いません。意味を持つのは記号と階層です。

1.3 コメント

※ からその行末まではコメントです。処理としては読まれず、コードの同じ位置に // のコメントとして写されます。

├─変数int priceにキーボードから価格を入力する ※税抜き価格
│  ※ここからは税込み価格の計算と表示
└─priceに1.1を掛けて整数に丸め、"税込=〇〇"の形式で表示する

int price = Input.getInt(); // 税抜き価格
// ここからは税込み価格の計算と表示
System.out.printf("税込=%d%n", Math.round(price * 1.1));
  • 引用符（"…"）や鉤括弧（「…」）の中の ※ は、コメントになりません。

1.4 SPDはコードの先頭に残る

生成されるコードの先頭には、SPD 全体がブロックコメント（/* … */）としてそのまま残ります。

/*
リストの要素を集計する
  │
  ├─整数のリストを作成して、変数listに代入する
  …
*/

import java.util.List;

public class ListAggregation {
    …
}
  • SPD は分けられず、1か所にまとめて置かれます。コードからコピーして、SPD エディタに戻せます。
  • import 文は自動で補われるので、SPD に書く必要はありません。

1.5 書きかけの部分はコードにならない

★ を含む行や、中身の無い 処理 があるメソッドは、書きかけとみなされ、コードが作られません。 推測で補われることはなく、代わりに次のようなコメント1行が置かれます。

└─メソッド：calcScore
     ├─目的：点数を計算する
     ├─引数：int[] hand
     ├─戻り値：int、点数
     └─処理
          └─★ここにSPDを書く★

// calcScoreメソッド：SPDが未記入のため生成していません
  • 書きかけかどうかは、メソッドやクラスの単位ごとに決まります。ほかの部分は、ふつうに生成されます。
  • 引数：なし・戻り値：なし・フィールド：なし のように なし と書いた項目は、書き終えたものとして扱われます。

第2章 順に実行する処理

2.1 変数と代入

変数は 変数<型> <名前> の形で書くと、その型で宣言されます。型を書かなければ、var になることがあります。

├─合計を入れる変数int totalを宣言してゼロを代入する
├─整数のリストを作成して、変数listに代入する
│    └─要素は(10, 20, 30)
└─km = mile * 1.609

int total = 0;
var list = List.of(10, 20, 30);
double km = mile * 1.609;
  • 代入は ← または = で書いても構いません（km = mile * 1.609）。
  • 型を明示したいときは、変数int total のように変数名の前に型を書きます。

2.2 キーボードからの入力

キーボードからの入力は、授業用の Input クラスで行います（Scanner は使いません）。

├─変数int ageにキーボードから年齢を入力する
├─身長（cm）を変数double heightに入力する（入力プロンプトは "身長>"）
└─変数String answerに、"Y:続ける, N:終了する"から選択させた値を代入する

int age = Input.getInt();
double height = Input.getDouble("身長>");
String answer = Input.getSelect("Y:続ける, N:終了する");
入力するもの 使われるメソッド
整数 Input.getInt()
実数 Input.getDouble()
文字列 Input.getString()
選択肢から選ぶ Input.getSelect("Y:はい, N:いいえ")（選んだ記号を大文字で返す）
  • 入力プロンプト（入力の前に表示する文字）を書くと、メソッドの引数になります。
  • 「選択肢」「メニュー」「選ぶ」と書くと、getSelect が使われます。

2.3 表示

├─memberをコンソールに表示する
└─合計を"合計＝〇〇"の書式でコンソールに表示する

System.out.println(member);
System.out.printf("合計＝%d%n", total);
  • "〇〇=△△" のように書式を示すと、printf で表示されます。〇〇 の部分に値が入ります。

2.4 四捨五入

SPD の書き方 生成されるコード
小数点以下2桁までに四捨五入する Tools.round(x, 2)
整数に丸める（小数点以下0桁） Math.round(x) 
└─kmを小数点以下2桁までに四捨五入して返す

return Tools.round(km, 2);
  • 桁数を指定した四捨五入は、授業用の Tools.round で行います。

第3章 分岐

3.1 if と else

分岐は ◇─条件 と書き、その下に条件が成り立つときの処理を書きます。成り立たないときの処理は └─else の下に書きます。

├─◇─scoreは60以上である
│  │    └─"合格"と表示する
│  └─else
│        └─"不合格"と表示する

if (score >= 60) {
    System.out.println("合格");
} else {
    System.out.println("不合格");
}

else が要らなければ、省きます。

├─◇─scoreは100である
│        └─"満点"と表示する

if (score == 100) {
    System.out.println("満点");
}

3.2 独立した if と else if の見分け方

◇ の左にある最初の文字で、新しい if か、上の ◇ に続く else if かが決まります。ここはとても大事です。

◇ の左の最初の文字（空白は飛ばす） 意味
│、または行頭 上の ◇ の続き → else if
─（├─◇・└─◇） 新しい分岐 → 独立した if

else if にするとき（2つ目の ◇ の左は │）

├─◇─scoreは80以上である
│  │    └─"A"と表示する
│  ◇─scoreは60以上である
│  │    └─"B"と表示する
│  └─else
│        └─"C"と表示する

if (score >= 80) {
    System.out.println("A");
} else if (score >= 60) {
    System.out.println("B");
} else {
    System.out.println("C");
}

独立した if を並べるとき（どちらの ◇ も左は ─）

├─◇─scoreは80以上である
│        └─"よくできました"と表示する
├─◇─欠席は3回以上である
│        └─"補習があります"と表示する

if (score >= 80) {
    System.out.println("よくできました");
}
if (absence >= 3) {
    System.out.println("補習があります");
}
  • 字下げの位置が同じでも、意味は違います。 見るのは ◇ の左の文字だけです。

3.3 switch

1つの値で場合分けするときは、◇─switch文: と書き、子に case を並べます。

└─◇─switch文: rankの値で判定
    ├─case "A"なら"優"と表示する
    ├─case "B"か"C"なら"良"と表示する
    └─default それ以外なら"可"と表示する

switch (rank) {
    case "A" -> System.out.println("優");
    case "B", "C" -> System.out.println("良");
    default -> System.out.println("可");
}

値を選んで変数に入れるときは、switch式 にします。

└─変数labelにswitch式の戻り値を代入する
       └─label=◇─switch式: rankの値で判定
             ├─case "A"なら "優"を返す
             └─default それ以外なら "可"を返す

var label = switch (rank) {
    case "A" -> "優";
    default -> "可";
};
  • 1つの case で複数の処理をするときは、case の右に ┬ を置き、その下に処理を並べます。

3.4 条件式

◇ を使わず、1行で「〜なら A を、それ以外なら B を代入する」と書くと、条件式（? :）になります。

├─numberが6なら"当たり"を、それ以外なら"はずれ"を変数messageに代入する

String message = number == 6 ? "当たり" : "はずれ";

第4章 繰り返し

繰り返しは ↻─ で表します。繰り返す処理は、その子に書きます。

4.1 リストの要素を順に処理する

└─↻─for: 変数nにlistから毎回１つずつ要素を取り出す
   └─nを表示する

for (var n : list) {
    System.out.println(n);
}
  • 要素を1つずつ取り出すときは、拡張 for 文になります。

4.2 回数を数えて繰り返す

└─↻─for: iを0から10未満まで1ずつ増やす
   └─iを表示する

for (int i = 0; i < 10; i++) {
    System.out.println(i);
}
  • 番号（インデックス）が必要なときだけ、この形を使います。

4.3 条件が成り立つ間繰り返す

└─↻─while: numberにキーボードから整数を入力し、それが0でない間繰り返す
   └─numberをtotalに加算する

while ((number = Input.getInt()) != 0) {
    total += number;
}

途中で抜けるときは、while: true と break を組み合わせます。

├─↻─while: true
│     ├─変数int nにキーボードから整数を入力する
│     ├─◇─nは0である
│     │  └─breakでループを脱出する
│     └─nをtotalに加算する

while (true) {
    int n = Input.getInt();
    if (n == 0) {
        break;
    }
    total += n;
}

第5章 例外処理

例外処理は 〇─try と 〇─catch: で表します。

5.1 try と catch

├─〇─try
│  │  └─textを整数に変換して変数int nに代入する
│  〇─catch:NumberFormatException e
│       └─"数字を入力してください"と表示する

try {
    int n = Integer.parseInt(text);
} catch (NumberFormatException e) {
    System.out.println("数字を入力してください");
}
  • catch の中では、少なくともメッセージを表示します。例外を何もせずに捨てる（握りつぶす）コードは作られません。

5.2 ファイルを開く（try-with-resources）

try: の右に、ファイルを開く式を書くと、自動で閉じる try-with-resources になります。

├─〇─try:var in = Files.newBufferedReader(path) によりファイルを開く
│  │  └─1行ずつ読んで表示する
│  〇─catch:IOException e
│       └─標準エラー出力にスタックトレースを表示する

try (var in = Files.newBufferedReader(path)) {
    String line;
    while ((line = in.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    e.printStackTrace();
}

5.3 例外を投げる

〜Exceptionを投げる と書き、子にメッセージを書きます。

├─◇─count は負である
│        └─IllegalArgumentExceptionを投げる
│              └─エラーメッセージは "不正な値" + count とする

if (count < 0) {
    throw new IllegalArgumentException("不正な値" + count);
}
  • 検査例外（IOException など）を投げるメソッドには、throws が自動で補われます。 メソッドの見出しに メソッド：doSomething throws MyException と書いておくこともできます。

第6章 メソッド

6.1 メソッドの形

メソッドは、見出しを クラスメソッド：<名前>（static）または メソッド：<名前>（インスタンスメソッド）とし、 子に 目的・引数・戻り値・処理 を書きます。

クラスメソッド: mile2km
│
├─目的:マイルをキロメートルに変換する
├─引数
│    └─マイルの値：double mile
├─戻り値：double、キロメートルの値
└─処理
      ├─km = mile * 1.609
      └─kmを小数点以下2桁までに四捨五入して返す

/**
 * マイルをキロメートルに変換する
 * @param mile マイルの値
 * @return キロメートルの値
 */
public static double mile2km(double mile) {
    double km = mile * 1.609;
    return Tools.round(km, 2);
}
  • 目的 が Javadoc になります。引数と戻り値の説明は、@param・@return になります。目的 を書かなければ、Javadoc は付きません。
  • クラスメソッド: main は main メソッドです。目的・引数・戻り値は省略できます。
  • 見出しのコロンは、全角の ： でも半角の : でも構いません。

6.2 引数と戻り値の書き方

項目 書き方 例
引数 <説明>：<型> <名前> か <型> <名前> : <説明> マイルの値：double mile
引数が1つ 引数 に続けて1行で書ける 引数：回数：int count
引数が無い 引数：なし
戻り値 <型>、<説明>（型が先） 戻り値：double、キロメートルの値
戻り値が無い 戻り値：なし
  • 戻り値は型を先に書きます。 キロメートルの値、double のように逆にすると読めません。
  • 処理の中で値を返すときは、〜を返す と書きます。

第7章 クラス

7.1 クラスの形

クラスは、タイトルを クラス：<名前> とし、メンバーを木の枝として並べます。

クラス：GeneralMember
│
├─目的：一般会員を表すクラス
│
├─フィールド
│  ├─番号：int uid
│  └─名前：String name
│
├─自動生成
│  ├─コンストラクタ：全引数
│  ├─ゲッター
│  └─toString
│
└─メソッド：greet
   ├─目的：挨拶を表示する
   ├─引数：なし
   ├─戻り値：なし
   └─処理
         └─"こんにちは、〇〇さん"の形式で名前を表示する

// 一般会員を表すクラス
public class GeneralMember {
    private int uid;     // 番号
    private String name; // 名前

    // 自動生成：コンストラクタ：全引数
    public GeneralMember(int uid, String name) {
        this.uid = uid;
        this.name = name;
    }

    // 自動生成：ゲッター
    public int getUid() {
        return uid;
    }

    public String getName() {
        return name;
    }

    // 自動生成：toString
    @Override
    public String toString() {
        return "GeneralMember[uid=" + uid + ", name=" + name + "]";
    }

    /** 挨拶を表示する */
    public void greet() {
        System.out.printf("こんにちは、%sさん%n", name);
    }
}
枝 書く内容 回数
目的 クラスの説明（クラスの直前のコメントになる） 1回
フィールド インスタンスの変数 1回
自動生成 自動で作るメンバー（7.3） 1回
コンストラクタ 自分で書くコンストラクタ（7.4） 何回でも
メソッド： インスタンスメソッド 何回でも
クラス変数・クラスメソッド： static のメンバー（7.5） 何回でも
  • 枝の順番は自由です。どの枝も省略できます（クラス名だけは必須です）。

7.2 フィールドとアクセス修飾子

フィールドは <説明>：<修飾子> <型> <名前> と書きます。説明は行末のコメントになります。

記号 アクセス修飾子
+ public
# protected
~ 修飾子なし（パッケージ内）
- private

省略したときの既定値

書くもの 既定値
フィールド private
クラス・メソッド・クラス変数・コンストラクタ public 
├─フィールド
│  ├─番号：int uid
│  └─種別：# String kind

private int uid;        // 番号
protected String kind;  // 種別

7.3 自動生成

決まった形のメンバーは、自動生成 に項目名を書くだけで作られます。書いたものだけが作られます。

項目 作られるもの
コンストラクタ：全引数 すべてのフィールドを引数に取るコンストラクタ
コンストラクタ：引数なし 引数も中身も無いコンストラクタ
ゲッター・セッター フィールドの get／set メソッド
toString toString()
等値判定 equals() と hashCode()
移譲メソッド 自作クラス型のフィールドのメソッドを呼ぶだけのメソッド
  • ← フィールド名 で、対象のフィールドを絞れます（等値判定 ← uid・ゲッター ← uid, name）。書かなければ、すべてのフィールドが対象です。
  • 先頭に修飾子を書けます（# コンストラクタ：全引数 → protected のコンストラクタ）。
  • 自動生成と同じ形のメソッドを メソッド： で書くと、そちらが優先されます。

7.4 コンストラクタとメソッド

自動生成で足りないコンストラクタは、コンストラクタ の枝に 引数 と 処理 を書きます。

├─コンストラクタ
│    ├─引数
│    │    └─CSV 文字列：String csv
│    └─処理
│          ├─csvをカンマで区切って配列itemsに代入する
│          ├─items[0]の前後の空白を除き、intに変換してuidに代入する
│          └─items[1]の前後の空白を除いてnameに代入する

public GeneralMember(String csv) {
    var items = csv.split(",");
    this.uid = Integer.parseInt(items[0].trim());
    this.name = items[1].trim();
}
  • インスタンスメソッドは メソッド：<名前>、private のメソッドは プライベートメソッド：<名前> と書きます。書き方は第6章と同じです。

7.5 クラス変数とクラスメソッド

static な変数は クラス変数、static なメソッドは クラスメソッド： に書きます。

├─クラス変数：
│  └─会費額：# final int FEE = 5000
│
└─クラスメソッド：main
     └─処理
          ├─（100, "田中宏" ）でインスタンスを作って変数memberに代入する
          └─memberをコンソールに表示する

protected static final int FEE = 5000; // 会費額

public static void main(String[] args) {
    var member = new GeneralMember(100, "田中宏");
    System.out.println(member);
}
  • final は、書いたときだけ付きます。クラス変数は、クラスの先頭に置かれます。

7.6 継承と実装

タイトルの後ろに、─⊳（継承）と ---⊳（実装）で書きます。

クラス: StudentMember ─⊳ Member ---⊳ Versionable, Comparable<StudentMember>

public class StudentMember extends Member implements Versionable, Comparable<StudentMember> {
  • 継承できるクラスは1つだけです。実装するインタフェースは、、 か , で区切って並べられます。
  • 親クラスのメソッドを上書きするメソッドには、@Override が自動で付きます。

第8章 インタフェース・抽象クラス・レコード

8.1 インタフェース

タイトルを インタフェース：<名前> とし、中身の無いメソッドを 抽象メソッド： で書きます。処理 は書きません。

インタフェース：Versionable
│
├─目的：バージョン番号を返す
│
└─抽象メソッド：version
       ├─目的：バージョン番号を返す
       ├─引数：なし
       └─戻り値：String、バージョン番号

/** バージョン番号を返す */
public interface Versionable {
    /**
     * バージョン番号を返す
     * @return バージョン番号
     */
    String version();
}
  • インタフェースには、クラス変数・デフォルトメソッド：（default）・クラスメソッド：・プライベートメソッド： も書けます。
  • インタフェースの継承は ─⊳ で書きます（インタフェース：A ─⊳ B）。

8.2 抽象クラス

タイトルを 抽象クラス：<名前> とします。書き方はクラスと同じで、抽象メソッド： も書けます。

抽象クラス：Member
│
├─フィールド
│    ├─番号：int uid
│    └─名前：String name
│
├─自動生成
│    └─# コンストラクタ：全引数
│
└─抽象メソッド：fee
      ├─目的：会費額を返す
      ├─引数：なし
      └─戻り値：int 、会費額

public abstract class Member {
    private int uid;     // 番号
    private String name; // 名前

    // 自動生成：コンストラクタ：全引数
    protected Member(int uid, String name) {
        this.uid = uid;
        this.name = name;
    }

    /**
     * 会費額を返す
     * @return 会費額
     */
    public abstract int fee();
}
  • 抽象クラスのコンストラクタは、サブクラスからだけ呼ばれるので、#（protected）を付けるのが定石です。

8.3 レコード

値をまとめるだけの型は、タイトルを レコード：<名前> とし、フィールド だけを書きます。

レコード:Product
│
├─目的:製品レコード
└─フィールド
      ├─型番: String number
      ├─品名: String name
      └─価格: int price

/** Product: 製品レコード */
public record Product(
    String number,   // 型番
    String name,     // 品名
    int price        // 価格

  • レコードの値は、number()・price() のように、フィールド名と同じ名前のメソッドで取り出します。

第9章 ラムダ式とストリーム

9.1 ラムダ式

ラムダ式は λ(引数)：<本体> と書きます。

├─listを重さ順に並べ替える─λ(a, b):aとbの重さを比較した結果を返す

list.sort((a, b) -> Integer.compare(a.weight(), b.weight()));
SPD 生成される式
λ(a):a の重さは300 以上 a -> a.weight() >= 300
λ(a, b):aとbの重さを比較した結果を返す (a, b) -> Integer.compare(…)
λ(a):a を表示する System.out::println（メソッド参照に書き換わる）
  • 処理の右に ─ でラムダ式をつなぐと、その処理の引数になります（上の sort の例）。
  • 本体が複数の処理なら、λ(a):┬ と書き、┬ の下に処理を並べます。
  • 単純な形のラムダ式は、System.out::println のようなメソッド参照に書き換えられます。

9.2 ストリーム処理

▽─stream:<コレクション> の子に、操作を1行に1つずつ上から並べます。

└─▽─stream:list
    ├─メーカー名（maker ）が"Panan" であるものだけをフィルタリングする
    ├─機種名（name ）のストリームに変換する
    └─すべての要素をprintln で表示する

list.stream()
    .filter(pc -> "Panan".equals(pc.maker()))
    .map(PC::name)
    .forEach(System.out::println);

結果を変数に入れるときは、変数←▽─stream:… と書きます。

└─names←▽─stream:list
          ├─機種名（name ）のストリームに変換する
          └─リストにする

List<String> names = list.stream()
        .map(PC::name)
        .toList();
SPD の言い方 操作
…だけをフィルタリングする filter
…のストリームに変換する map
…でソートする sorted
リストにする toList()
…で連結した文字列を作成する collect(joining(…))
合計を求める・個数を数える sum()・count()
表示する forEach(…)
  • 最後の行は、結果を作る操作（終端操作）にします。 無ければストリームは動きません。
  • フィールド名を括弧で添える（メーカー名（maker ））と、確実にその名前が使われます。
  • Files.lines(path) のようにストリームを返す式は、▽─Files.lines(path) と直接書けます。

第10章 まとめ

10.1 完全な例

リストの要素を集計する
  │
  ├─整数のリストを作成して、変数listに代入する
  │    └─要素は(10, 20, 30)
  ├─合計を入れる変数int totalを宣言してゼロを代入する
  ├─↻─ for:変数nにlistから毎回１つずつ要素を取り出す
  │       └─ nをtotalに加算する
  ├─平均を計算して変数double aveに代入する
  │    └─平均は、doubleに変換したtotalをlistの要素数で割り、小数点以下1桁までに四捨五入する
  ├─合計を"合計＝〇〇"の書式でコンソールに表示する
  └─平均を"平均＝〇〇"の書式でコンソールに表示する

/*
（SPD 全体）
*/

import java.util.List;
import jp.kwebs.tools.Tools;

public class ListAggregation {
    public static void main(String[] args) {
        var list = List.of(10, 20, 30);

        int total = 0;
        for (var n : list) {
            total += n;
        }

        double ave = Tools.round((double) total / list.size(), 1);

        System.out.printf("合計＝%d%n", total);
        System.out.printf("平均＝%.1f%n", ave);
    }
}
