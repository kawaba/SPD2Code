SPDによるテンプレートの書き方

Spring Boot の画面（Thymeleaf テンプレート）を SPD で設計するための入門書です。 規約（thymeleaf.instructions.md）のうち、初めて書くときに知っておきたいことだけを選んで説明します。 細かい規則や例外は省いていますので、迷ったときは規約を参照してください。

各節では、SPD の例と、そこから生成されるテンプレート（HTML）を対にして示します。

第1章 テンプレートSPDの全体像

1.1 全体の形

テンプレートの SPD は、タイトルを テンプレート：<名前> とし、その下に設定の項目と 構成 を書きます。 構成 が画面の中身です。

テンプレート：member/list
│
├─目的：会員の一覧を表示する
├─レイアウト：なし
├─タイトル：会員一覧
├─css：css/style.css
│
├─受け取り
│  ├─会員リスト：List<Member> memberList
│  └─メッセージ：String message　※任意
│
└─構成
     ├─［見出し］会員一覧
     └─［リンク］新規登録 → /members/new
項目 意味
テンプレート：member/list 作るファイル。templates/member/list.html になります
目的 何の画面か。ファイルの先頭のコメントに残ります
レイアウト 共通レイアウトを使うかどうか。初めは なし で構いません
タイトル ブラウザのタブに出る題（<title>）
css 読み込むスタイルシート。static/ からの位置で書きます
受け取り コントローラーから渡される値
構成 画面に並べるもの（第2章から説明します）

生成されるテンプレートの骨格は、次のようになります。

<!--/*
テンプレート：member/list
…（SPD 全体がここに残る）…
*/-->
<!doctype html>
<html xmlns:th="http://www.thymeleaf.org" lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" th:href="@{/css/style.css}">
  <title>会員一覧</title>
</head>
<body>
  <h1>会員一覧</h1>
  <a th:href="@{/members/new}">新規登録</a>
</body>
</html>
  • 構成 の中身が <body> の中に、書いた順に並びます。
  • SPD はテンプレートの先頭にコメントとして残ります。 このコメント（<!--/* … */-->）はブラウザには送られません。

1.2 受け取り

受け取り には、コントローラーがテンプレートに渡す値を <説明>：<型> <名前> の形で書きます。

├─受け取り
│  ├─会員リスト：List<Member> memberList
│  └─メッセージ：String message　※任意
  • <名前> は、コントローラーの SPD で「〜をテンプレートに渡す」と書いた名前と同じにします。 ここがずれると、画面に値が出ません。
  • 画面の中では、この名前を使って値を取り出します（{memberList}・{message}。1.4 で説明します）。
  • 渡されないことがある値には ※任意 を付けます。※任意 の値は、条件を付けて表示します（第5章）。
  • 何も受け取らない画面は 受け取り：なし と書きます。

1.3 構成の行の書き方

構成 の中の行は、次の 4つの形 のどれかで書きます。形によって意味が決まります。

形 意味 例
［種類］… ノード：見出し・リンク・表などの部品 ［見出し］会員一覧
ラベル：値 表示：ラベルと値を並べて見せる 名前：{m.name}
ラベル＜種類＞：名前 入力：入力欄を作る 名前＜text＞：name
キャプション＜種類＞ ボタン 登録する＜submit＞

これに加えて、次の印を使います。

印 意味 例
→ パス リンクの行き先・フォームの送信先 ［リンク］戻る → /members
(条件) 条件が成り立つときだけ表示する（第5章） ({message}は空ではない) ［通知］{message}
<<…>> 書式・クラス名・画像のサイズ（第4章） {m.joinedOn} <<"yyyy年MM月dd日">>

覚えておきたい決まりは次の3つです。

  • ［…］ で始まる行だけがノードです。 ： はいつもラベルと値の区切りです。
  • ラベル：値 を書けるのは、表（第3章）の中とフォーム（第6章）の中だけです。 構成 の直下に値を1つ出したいときは、［段落］・［文字］ を使います。
  • ［…］ も ： も ＜…＞ も無い、文字だけの行は書けません。 文字を出すときも ［文字］在庫あり のように書きます。

1.4 変数 {…}

値の中で 半角の {…} で囲んだ部分が変数で、それ以外は書いたとおりの文字として表示されます。 {…} の中は、受け取り の名前（または繰り返しの変数）から書き始めます。

└─構成
     ├─［見出し］会員一覧
     ├─［見出し］{title}
     └─［段落］{member.name}さん、ようこそ

<h1>会員一覧</h1>
<h1 th:text="${title}">表題</h1>
<p th:text="|${member.name}さん、ようこそ|">nameさん、ようこそ</p>
  • {…} の無い文字は、HTML にそのまま書かれます。
  • {…} のある値は th:text で出力されます。 文字と変数が混ざっていれば |…| の形になります。
  • タグの中の 表題・name は、プレビュー用のダミーです。テンプレートをブラウザで直接開いたときに表示され、 アプリとして動かしたときは本当の値に置き換わります。ダミーは規則に従って自動で決まるので、SPD に書く必要はありません。
  • {…} は必ず半角で書きます。 全角の ｛…｝ は変数になりません。

第2章 画面に部品を置く

2.1 見出し・段落・区切り・文字

画面の部品は ［種類］値 の形で書きます。よく使うものは次のとおりです。

└─構成
     ├─［見出し］会員一覧
     ├─［小見出し］お知らせ
     ├─［段落］毎月1日に更新します。
     ├─［区切り］
     └─［文字］{member.name}

<h1>会員一覧</h1>
<h2>お知らせ</h2>
<p>毎月1日に更新します。</p>
<hr>
<span th:text="${member.name}">name</span>
ノード 生成される要素
［見出し］ <h1>
［小見出し］ <h2>
［段落］ <p>
［区切り］ <hr>（値を書きません）
［文字］ 変数があれば <span>、無ければ文字だけ
［通知］ <div class="message">（2.5）

2.2 リンクとパス

［リンク］<表示する文字> → <パス> と書きます。パスには変数を入れられます。

└─構成
     ├─［リンク］新規登録 → /members/new
     └─［リンク］{member.name}を編集 → /members/{member.id}/edit

<a th:href="@{/members/new}">新規登録</a>
<a th:href="@{/members/{id}/edit(id=${member.id})}" th:text="|${member.name}を編集|">nameを編集</a>
  • パスは / から始まる絶対パスで書きます。コントローラーの URL と同じにします。
  • パスの中の {member.id} のような変数は、Thymeleaf の {id}(id=…) の形に変換されます。

2.3 画像

［画像］<パス> "<代替文字列>" <<サイズ>> と書きます。代替文字列とサイズは省略できます。

└─構成
     ├─［画像］/images/logo.png "会社のロゴ" <<120px>>
     └─［画像］/images/{member.photo}

<img th:src="@{/images/logo.png}" alt="会社のロゴ" width="120">
<img th:src="@{/images/{photo}(photo=${member.photo})}" alt="">
  • パスは static/ フォルダーからの位置を / から書きます（static/images/logo.png → /images/logo.png）。
  • サイズは 幅を px 付きで書きます。高さは縦横の比を保って自動で決まります。
  • 代替文字列を省略すると alt="" になります。

2.4 段落の中に複数の部品を並べる

文字・変数・リンク・画像を1つの文の中に並べたいときは、値を書かずに ［段落］ の子に並べます。

└─構成
     └─［段落］
          ├─［文字］ようこそ、
          ├─［文字］{member.name}
          ├─［文字］さん。
          ├─［改行］
          ├─［文字］詳しくは
          └─［リンク］こちら → /about

<p>ようこそ、<span th:text="${member.name}">name</span>さん。<br>
詳しくは<a th:href="@{/about}">こちら</a></p>
  • 子に書けるのは ［文字］・［リンク］・［画像］・［改行］ の4つだけです。
  • ［改行］ は、このように部品を並べる途中でだけ使えます（<br>）。段落と段落の間を空けるためには使いません（間隔は CSS で決めます）。
  • 子が ［文字］ だけなら、［段落］ようこそ、{member.name}さん。 と1行で書けます。

2.5 通知

処理の結果のメッセージ（「登録しました」など）は ［通知］ で表示します。

└─構成
     └─［通知］{message}

<div class="message" th:text="${message}">メッセージ</div>
  • class="message" が必ず付くので、CSS でメッセージの見た目を決めておけます。
  • メッセージは渡されないこともあるので、実際には条件を付けて書きます（第5章の 5.1）。

第3章 表と箇条書き

3.1 一覧の表 ― 表（列）

リストの要素を1行ずつ並べる表は ［表（列）］<リスト>の各要素を<変数>とする と書きます。 子の1行が表の1列になります。列は 見出し：値 の形で書きます。

└─構成
     └─［表（列）］memberListの各要素をmとする
          ├─番号：{m.id}
          ├─名前：{m.name}
          └─：［リンク］編集 → /members/{m.id}/edit

<table>
  <thead>
    <tr>
      <th>番号</th>
      <th>名前</th>
      <th></th>
    </tr>
  </thead>
  <tbody>
    <tr th:each="m : ${memberList}">
      <td th:text="${m.id}">番号</td>
      <td th:text="${m.name}">名前</td>
      <td><a th:href="@{/members/{id}/edit(id=${m.id})}">編集</a></td>
    </tr>
  </tbody>
</table>
  • ： の左が列見出し（<th>）、右がマスの値（<td>）になります。
  • 「〜の各要素を〜とする」の変数（ここでは m） で、1行分の要素を指します。th:each は <tr> に付きます。
  • 見出しの要らない列は、： の左を空にします（：［リンク］編集 → …）。
  • 値の位置には、［リンク］・［画像］・［文字］・［通知］ を書けます。

1つのマスに複数の部品を置く

値を書かずに 見出し： の子に並べると、子が1つのマスに入ります。行ごとの「編集」「削除」などに使います。

└─構成
     └─［表（列）］memberListの各要素をmとする
          ├─名前：{m.name}
          └─操作：
               ├─［リンク］編集 → /members/{m.id}/edit
               ├─［文字］|
               └─［フォーム］→ POST /members/{m.id}/delete
                    └─削除＜submit＞

<tr th:each="m : ${memberList}">
  <td th:text="${m.name}">名前</td>
  <td>
    <a th:href="@{/members/{id}/edit(id=${m.id})}">編集</a>
    |
    <form th:action="@{/members/{id}/delete(id=${m.id})}" method="post">
      <button type="submit">削除</button>
    </form>
  </td>
</tr>
  • 削除のように ボタンを置くときは、ボタンだけの ［フォーム］ を子に置きます（フォームは第6章）。

3.2 詳細の表 ― 表（行）

1件のデータを「左に項目名・右に値」の形で見せる表は ［表（行）］ と書きます。子の1行が表の1行になります。繰り返しはありません。

├─受け取り
│  └─会員：Member member
│
└─構成
     ├─［見出し］会員詳細
     └─［表（行）］
          ├─番号：{member.id}
          ├─名前：{member.name}
          ├─写真：［画像］/images/{member.photo} <<120px>>
          └─［リンク］一覧へ戻る → /members

<h1>会員詳細</h1>
<table>
  <tr>
    <td>番号</td>
    <td th:text="${member.id}">番号</td>
  </tr>
  <tr>
    <td>名前</td>
    <td th:text="${member.name}">名前</td>
  </tr>
  <tr>
    <td>写真</td>
    <td><img th:src="@{/images/{photo}(photo=${member.photo})}" alt="" width="120"></td>
  </tr>
  <tr>
    <td colspan="2"><a th:href="@{/members}">一覧へ戻る</a></td>
  </tr>
</table>
  • ： がある行は2マス（左がラベル、右が値）になります。
  • ： が無い ［…］ の行は、2マスを結合した1マス（colspan="2"）になります。
  • 表（列）と同じく、ラベル： の子に並べれば、右のマスに複数の部品を置けます。
  • 表（行）は、フォームの入力画面でもよく使います（第6章）。

3.3 箇条書き

リストの要素を箇条書きにするときは ［箇条書き］<リスト>の各要素を<変数>とする と書き、子に ［項目］ を1行書きます。

└─構成
     └─［箇条書き］memberListの各要素をmとする
          └─［項目］{m.name}

<ul>
  <li th:each="m : ${memberList}" th:text="${m.name}">name</li>
</ul>

［項目］ も、［段落］ と同じく値を書かずに子に並べられます。リンクの一覧などに使います。

└─構成
     └─［箇条書き］memberListの各要素をmとする
          └─［項目］
               ├─［リンク］{m.name} → /members/{m.id}
               └─［文字］（{m.age}歳）

<ul>
  <li th:each="m : ${memberList}"><a th:href="@{/members/{id}(id=${m.id})}" th:text="${m.name}">name</a><span th:text="|（${m.age}歳）|">（age歳）</span></li>
</ul>
  • ［箇条書き］ の子は ［項目］ の1行だけです。

第4章 見た目を整える

4.1 値の書式

値の後に <<書式>> を書くと、日付や数を整えて表示します。

└─［表（行）］
     ├─入会日：{member.joinedOn} <<"yyyy年MM月dd日">>
     └─ポイント：{member.point} <<3桁区切り>>

<tr>
  <td>入会日</td>
  <td th:text="${member.joinedOn == null ? '' : #temporals.format(member.joinedOn, 'yyyy年MM月dd日')}">入会日</td>
</tr>
<tr>
  <td>ポイント</td>
  <td th:text="${member.point == null ? '' : #numbers.formatInteger(member.point, 1, 'COMMA')}">ポイント</td>
</tr>

使える書式は次の4つです。

書式 表示の例 使える型
"yyyy年MM月dd日"（日付・時刻のパターン） 2026年03月05日 LocalDate・LocalDateTime・LocalTime
3桁区切り 12,345 整数
円表示 12,345円 整数
"、"で連結 国語、数学 List など
  • 値が null のときは空欄になります。
  • 書式を付けられるのは、{…} が1つだけの値です（{a}と{b} のような値には付けられません）。
  • 日付のパターンでは、MM が月、mm が分です。取り違えに注意してください。

4.2 CSSクラス

<<…>> の中に .クラス名 を書くと、その要素に class が付きます。見た目はクラスを使って CSS ファイルで決めます。

└─構成
     ├─［見出し］会員一覧 <<.中央揃え>>
     ├─［段落］{member.note} <<.改行保持>>
     └─［表（行）］ <<.詳細表>>
          └─価格：{price} <<円表示 .右寄せ>>

<h1 class="中央揃え">会員一覧</h1>
<p th:text="${member.note}" class="改行保持">note</p>
<table class="詳細表">
  <tr>
    <td>価格</td>
    <td th:text="${price == null ? '' : #numbers.formatInteger(price, 1, 'COMMA') + '円'}" class="右寄せ">価格</td>
  </tr>
</table>

/* css：に書いたファイル（例：static/css/style.css）に定義する */
.中央揃え { text-align: center; }
.改行保持 { white-space: pre-wrap; }
.右寄せ   { text-align: right; }
  • 書式とクラス名の両方を書くときは、書式を先に書きます（<<円表示 .右寄せ>>）。
  • クラス名を付けられる主なものは、見出し・段落・箇条書き・項目・表・画像・リンクと、{…} を含む値です。
  • 表は <table> に付けたクラスを使って、行の縞模様などを CSS で決めます（.詳細表 tr:nth-child(even)）。
  • style 属性は生成されません。 見た目の指定は、すべて CSS ファイルに書きます。

第5章 条件で表示を切り替える

5.1 条件の書き方

行の先頭か値の先頭に (条件) を書くと、条件が成り立つときだけ表示します（th:if）。 条件は {変数}は<比べる値><言い方> と書きます。

└─構成
     ├─({message}は空ではない) ［通知］{message}
     ├─({memberList}は空である) ［段落］会員が登録されていません。
     └─({member.point}は100以上) ［段落］ゴールド会員です。

<div class="message" th:if="${not #strings.isEmpty(message)}" th:text="${message}">メッセージ</div>
<p th:if="${#lists.isEmpty(memberList)}">会員が登録されていません。</p>
<p th:if="${member.point ge 100}">ゴールド会員です。</p>

使える言い方は次のとおりです。

言い方 意味
より大きい・より小さい・以上・以下 大小を比べる（{a}は10以上）
である・ではない 等しいか（{kind}は"general"である）
({flag})・{flag}はfalseである boolean の値
空である・空ではない 文字列やリストが空か
nullである・nullではない 値が無いか
かつ・または 条件をつなぐ（{a}は10以上かつ20以下）
  • 文字列は "…" で囲みます。
  • 文字列を表示できるか確かめるときは 空ではない を使います。 nullではない では空文字を通してしまいます。
  • 「そうでなければ」の書き方はありません。 反対の条件を書いた行を並べます（5.2 の在庫の例）。
  • 計算（{a}は{b}*2より大きい）や件数（{list}の件数は5以上）は書けません。

5.2 条件を付ける場所

(条件) は、すぐ後に書いたものに付きます。どこに書くかで、消えるものが変わります。

書き方 消えるもの
(条件) ［ノード］… そのノード（入力項目・ボタンも同じ）
(条件) ラベル：値 表（行）の行ごと
ラベル：(条件) 値 値だけ（ラベルは残る）
(条件) だけの行に子を置く 子全部

表（行）の中での例を示します。

└─［表（行）］
     ├─({member.note}は空ではない) 備考：{member.note}
     ├─会員種別：({member.premium}) プレミアム
     └─在庫：
          ├─({stock}は10未満) ［文字］残りわずか
          └─({stock}は10以上) ［文字］在庫あり

<table>
  <tr th:if="${not #strings.isEmpty(member.note)}">
    <td>備考</td>
    <td th:text="${member.note}">備考</td>
  </tr>
  <tr>
    <td>会員種別</td>
    <td><span th:if="${member.premium}">プレミアム</span></td>
  </tr>
  <tr>
    <td>在庫</td>
    <td>
      <span th:if="${stock lt 10}">残りわずか</span>
      <span th:if="${stock ge 10}">在庫あり</span>
    </td>
  </tr>
</table>
  • 1行目は行の先頭に書いたので、行ごと消えます。
  • 2行目は値の先頭に書いたので、値だけ消え、ラベルの 会員種別 は残ります。
  • 3行目は子の1つずつに条件を付け、反対の条件を並べて「そうでなければ」を表しています。

まとめて消す

複数の部品をまとめて消すときは、(条件) だけの行を書き、その子に部品を並べます。

└─構成
     ├─({memberList}は空ではない)
     │    ├─［小見出し］会員一覧
     │    └─［表（列）］memberListの各要素をmとする
     │         ├─番号：{m.id}
     │         └─名前：{m.name}
     └─({memberList}は空である) ［段落］会員がいません

<th:block th:if="${not #lists.isEmpty(memberList)}">
  <h2>会員一覧</h2>
  <table>…</table>
</th:block>
<p th:if="${#lists.isEmpty(memberList)}">会員がいません</p>
  • <th:block> は Thymeleaf だけの要素で、ブラウザには何も出力されません。

繰り返しの中の条件

表（列）や箇条書きの中では、条件に要素の変数を使えます。

└─［箇条書き］memberListの各要素をmとする
     └─({m.active}) ［項目］{m.name}

<ul>
  <li th:each="m : ${memberList}" th:if="${m.active}" th:text="${m.name}">name</li>
</ul>
  • 表（列）で条件を付けられるのは、マスの値（名前：({m.active}) {m.name}）です。列の行頭には書けません（列見出しは消せないため）。

5.3 条件を取り除いても正しい行にする

(条件) は、正しい行の先頭に付ける印です。条件を取り除いた行が正しくなければ、書けません。

書けない 正しい書き方
({flag}) 在庫あり（条件を除くと文字だけの行） ({flag}) ［文字］在庫あり

第6章 フォーム

6.1 入力画面の基本

入力画面は、［フォーム］<オブジェクト名> → <メソッド> <パス> の子に、入力項目とボタンを書きます。 入力項目は ラベル＜種類＞：フィールド名、ボタンは キャプション＜種類＞ です。

├─受け取り
│  └─入力内容：MemberForm memberForm
│
└─構成
     ├─［見出し］会員登録
     └─［フォーム］memberForm → POST /members
          ├─［表（行）］
          │    ├─名前＜text＞：name
          │    ├─入会日＜date＞：joinedOn
          │    └─会員種別＜radio＞：kind
          │         ├─一般：general
          │         └─学生：student
          └─登録する＜submit＞

<h1>会員登録</h1>
<form th:object="${memberForm}" th:action="@{/members}" method="post">
  <table>
    <tr>
      <td><label for="name">名前</label></td>
      <td>
        <input type="text" th:field="*{name}">
        <span class="error-msg" th:if="${#fields.hasErrors('name')}" th:errors="*{name}">エラー</span>
      </td>
    </tr>
    <tr>
      <td><label for="joinedOn">入会日</label></td>
      <td>
        <input type="date" th:field="*{joinedOn}">
        <span class="error-msg" th:if="${#fields.hasErrors('joinedOn')}" th:errors="*{joinedOn}">エラー</span>
      </td>
    </tr>
    <tr>
      <td>会員種別</td>
      <td>
        <label><input type="radio" th:field="*{kind}" value="general"> 一般</label>
        <label><input type="radio" th:field="*{kind}" value="student"> 学生</label>
        <span class="error-msg" th:if="${#fields.hasErrors('kind')}" th:errors="*{kind}">エラー</span>
      </td>
    </tr>
  </table>
  <button type="submit">登録する</button>
</form>
  • オブジェクト名は、フォームクラスの名前の先頭を小文字にしたもの（MemberForm → memberForm）で、受け取り にも書きます。
  • ＜種類＞ は省略できません。 1行の文字入力も ＜text＞ と書きます。
  • フィールド名は {…} で囲みません。 ： の右に書いた名前で、値が送られます。
  • 入力項目には、入力エラーの表示が自動で付きます（class="error-msg"）。
  • 入力項目を ［表（行）］ に入れると、ラベルと入力欄が左右に並びます。入れずに ［フォーム］ の直下に書くと、1項目が1つの <div> になります。

6.2 入力項目の種類

種類 入力欄
＜text＞ 1行の文字
＜number＞・＜date＞・＜time＞・＜email＞・＜password＞ など 数・日付・時刻・メール・パスワードなど
＜textarea＞ 複数行の文字
＜radio＞ ラジオボタン（選択肢を子に書く）
＜select＞ プルダウン（選択肢を子に書く）
＜checkbox＞ チェックボックス（子が無ければ1つ、子があれば選択肢ごと）
＜hidden＞ 画面に出さずに送る値（更新画面の番号など）
  • 選択肢は、子に 表示名：値 と書きます（一般：general）。
  • ボタンは ＜submit＞（送信）と ＜reset＞（入力を元に戻す）の2つです。

6.3 編集画面 ― 表示だけの項目と hidden

フォームの中でも ラベル：{…} と書いた項目は、入力欄にならず値を表示するだけです。 編集画面で、変えられない会員番号を見せるときなどに使います。

└─［フォーム］memberForm → POST /members/update
     ├─［表（行）］
     │    ├─会員番号：{memberForm.id}
     │    └─名前＜text＞：name
     ├─番号＜hidden＞：id
     └─更新する＜submit＞

<form th:object="${memberForm}" th:action="@{/members/update}" method="post">
  <input type="hidden" th:field="*{id}">
  <table>
    <tr>
      <td>会員番号</td>
      <td th:text="*{id}">会員番号</td>
    </tr>
    <tr>
      <td><label for="name">名前</label></td>
      <td>
        <input type="text" th:field="*{name}">
        <span class="error-msg" th:if="${#fields.hasErrors('name')}" th:errors="*{name}">エラー</span>
      </td>
    </tr>
  </table>
  <button type="submit">更新する</button>
</form>
  • {…} で書くのは画面に出す値、： の後にそのまま書くのは送る名前です。この違いが、表示と入力の違いになります。
  • 表示だけの項目は送信されません。値を送るには、別に ＜hidden＞ を書きます。
  • 表示する値は、フォームの中でも {memberForm.id} のように受け取りの名前から書きます。生成するときに *{id} に変換されます。

6.4 ボタンを並べる

フォームの中の ［表（行）］ では、ボタンやリンクを1つのマスに並べられます。並べ方は2つあります。

└─［フォーム］memberForm → POST /members
     └─［表（行）］
          ├─名前＜text＞：name
          └─［空］：
               ├─登録する＜submit＞
               └─［リンク］キャンセル → /members

<tr>
  <td></td>
  <td>
    <button type="submit">登録する</button>
    <a th:href="@{/members}">キャンセル</a>
  </td>
</tr>
  • ［空］： の子に並べると、右のマス（入力欄の列）にそろいます。［空］ は、ラベルが空であることを表す印です。
  • ┬ でまとめると、2マスを結合した1マスに並びます。1つ目を ┬ の右に、2つ目からを ┬ の下に書きます。
          └─┬─登録する＜submit＞ <<.中央揃え>>
             └─［リンク］キャンセル → /members

<tr>
  <td colspan="2" class="中央揃え">
    <button type="submit">登録する</button>
    <a th:href="@{/members}">キャンセル</a>
  </td>
</tr>

6.5 ボタンだけのフォーム

オブジェクト名を省略したフォームは、削除ボタンや、別の画面へ移るボタンに使います。

└─構成
     ├─［フォーム］→ POST /members/{member.id}/delete
     │    └─削除＜submit＞
     └─［フォーム］→ GET /members
          └─戻る＜submit＞

<form th:action="@{/members/{id}/delete(id=${member.id})}" method="post">
  <button type="submit">削除</button>
</form>
<form th:action="@{/members}" method="get">
  <button type="submit">戻る</button>
</form>
  • メソッドを省略すると POST になります。
  • フォームの中にフォームは置けません。 入力フォームの表の中に削除ボタンを置くことはできません。

6.6 選択肢をリストから作る

部署の一覧のように、コントローラーから受け取ったリストで選択肢を作るときは、入力項目の子に <リスト>の各要素を<変数>とする を書き、その子に {表示名}：{値} を1行書きます。

├─受け取り
│  ├─入力内容：MemberForm memberForm
│  └─部署リスト：List<Department> departments
…
          ├─所属＜select＞：departmentId
          │    └─departmentsの各要素をdとする
          │         └─{d.name}：{d.id}

<select th:field="*{departmentId}">
  <option value="">選択してください</option>
  <option th:each="d : ${departments}" th:value="${d.id}" th:text="${d.name}">name</option>
</select>
  • 固定の選択肢（一般：general）とは、{…} の有無で見分けます。
  • ＜select＞ には、先頭に「選択してください」が自動で付きます。

6.7 フォームクラスを使わない入力

入力した値をそのまま受け取るだけの簡単な画面では、オブジェクト名を省略したフォームに入力項目を置けます。 このとき ： の右は、リクエストパラメーターの名前になります。

└─［フォーム］→ POST /test
     ├─名前＜text＞：name
     └─送信する＜submit＞

<form th:action="@{/test}" method="post">
  <div><label for="name">名前</label> <input type="text" id="name" name="name"></div>
  <button type="submit">送信する</button>
</form>
  • 入力エラーの表示は付きません。送信後に同じ画面を出すと、入力した値は消えます。
  • 値を残したい画面や、入力をチェックしたい画面では、フォームクラスを使います（6.1）。

7.2 よくある間違い

規約に合わない書き方は、推測で補われることはなく、生成されずに 【確認事項】として報告されます。よくある間違いを挙げます。

間違い 正しい書き方 理由
構成 の直下に 名前：{member.name} ［段落］{member.name}、または ［表（行）］ の子に書く ラベル：値 は表とフォームの中だけ
在庫あり（文字だけの行） ［文字］在庫あり 文字だけの行は書けない
名前：name（フォームの中） 名前＜text＞：name ＜種類＞ の書き忘れ
名前＜text＞：{name} 名前＜text＞：name フィールド名は {…} で囲まない
｛m.name｝（全角の中括弧） {m.name}（半角） 変数の中括弧は半角だけ
<<"yyyy/mm/dd">> <<"yyyy/MM/dd">> mm は分、MM が月
({flag}) 在庫あり ({flag}) ［文字］在庫あり 条件を除いて正しい行にする
案内：詳しくは［リンク］こちら → /about 案内： の子に ［文字］詳しくは と ［リンク］こちら → /about を並べる 値の位置には部品を1つだけ置ける。文字と混ぜられない
受け取り に無い名前を使う 受け取り に書き、コントローラーと名前をそろえる 値がテンプレートに渡らない

7.3 記号の早見表

記号 使い方 例
［…］ ノードの種類 ［見出し］・［表（列）］
： ラベルと値の区切り 名前：{m.name}
{…} 変数（半角だけ） {member.name}
＜…＞ 入力項目・ボタンの種類 ＜text＞・＜submit＞
→ 行き先・送信先 → /members/new・→ POST /members
<<…>> 書式・クラス名・画像のサイズ <<3桁区切り .右寄せ>>・<<120px>>
(…) 条件 ({message}は空ではない)
［空］ 空のラベル ［空］：
┬ 表（行）の1マスに部品を並べる ┬─登録する＜submit＞
← 目次へ戻る
