### 17. 関数定義のパターン

```
関数: 関数名
  ├─目的：説明
  ├─引数
  │    └─型　名前　説明
  ├─戻り値
  │    └─型　説明
  └─処理
        └─実装内容
```

```c
戻り値型 関数名(引数型 引数名);

// 概要・目的
戻り値型 関数名(引数型 引数名) {
    実装内容;
}
```

関数を作成する場合は、セクション2のルールに従い、関数プロトタイプ宣言を必ず作成し、関数の直前には1行コメントを付ける。

**static 関数（ファイル内専用の関数）**

関数名の前に `static` を付けると、その関数を**ファイル内専用**として生成する。

```
関数: static textureIndex
  ├─目的：Card からテクスチャ配列 cardTextures の添字を求める
  ├─引数
  │    └─Card card: 対象のカード（suit: 0〜3、rank: 1〜13）
  ├─戻り値
  │    └─int: 配列の添字（0〜51）
  └─処理
        └─suit × 13 + (rank − 1) を返す
```

```c
static int textureIndex(Card card);

// Card からテクスチャ配列 cardTextures の添字を求める
static int textureIndex(Card card) {
    return card.suit * 13 + (card.rank - 1);
}
```

- 関数定義とプロトタイプ宣言の両方に `static` を付ける。
- static 関数のプロトタイプ宣言は **`.c` ファイルの先頭**（グローバル変数の後）に置き、
  **ヘッダ（`.h`）には載せない**（セクション18.5.4「プロトタイプ宣言部は非 static 関数から生成する」と整合）。
