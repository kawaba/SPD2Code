### 14. 制御構造のパターン

#### 14.1 分岐（`◇`）

**【最優先・厳守】`◇` を `if` にするか `else if` にするかの判定規則**

判定は、次の文字テストだけで行う。

1. その `◇` から左へ、空白（半角・全角・タブ）を読み飛ばす。
2. 最初に現れた非空白文字を見る。

| 最初の非空白文字 | 意味 | 生成するC |
|---|---|---|
| `│`、または行頭まで空白しかない | 直上の `◇` の続き | **`else if`** |
| **それ以外のすべて**（`─` `├` `└` `=` など） | 新しい枝の開始 | **独立した `if`**（分岐の先頭） |

- **桁位置（字下げ）の一致を判定材料にしてはならない。** 独立した `if` が連続する場合も `else if` の連鎖の場合も `◇` の開始桁は一致するため、桁位置では区別できない。
- `◇` が縦に連続していること自体は `else if` の根拠にならない。根拠は上の表の1点のみである。
- 判定が付かない場合は、**必ず独立した `if`** とする。`else if` は「`│` または行頭のみが先行する」という積極的な根拠があるときだけ生成する。
- SPDが長くても分岐が多くても、この判定を `◇` 1個ごとに毎回行う。

**パターンA：if / else**

```
├─◇─条件
│  │   └─真の場合の処理
│  └─ else
│       └─偽の場合の処理
```

```c
if (条件) {
    真の場合の処理;
} else {
    偽の場合の処理;
}
```

**パターンB：単独のif（elseなし）**

```
├─◇─条件
│       └─ 処理
```

```c
if (条件) {
    処理;
}
```

**パターンB-2：独立したifが連続する場合（`else if` にしてはならない）**

`◇` の左に罫線 `─`（`├─◇` / `└─◇`）があるものは、縦に並んでいても**それぞれ独立した `if`** である。

```
├─◇─条件1
│       └─処理1
├─◇─条件2
│       └─処理2
```

```c
// どちらも ◇ の左が ─ なので、独立した if を2つ生成する
if (条件1) {
    処理1;
}
if (条件2) {
    処理2;
}
```

**誤り例**：上のSPDを次のように変換してはならない。

```c
if (条件1) {
    処理1;
} else if (条件2) {   // ← 誤り。◇ の左は ─ であって │ ではない
    処理2;
}
```

**パターンC：if / else if / else（`◇` の縦の連続）**

```
├─結果を表示する─◇─条件1
│                  │    └─処理1
│                  ◇─条件2
│                  │    └─処理2
│                  └─else
│                        └─デフォルト処理
```

```c
if (条件1) {
    処理1;
} else if (条件2) {
    処理2;
} else {
    デフォルト処理;
}
```

ここで2つ目の `◇` が `else if` になるのは、その左が `│` と空白だけで罫線 `─` が無いためである（`├─◇` になっていない）。1つ目の `◇` は左が `─` なので分岐の先頭、すなわち `if` である。

**パターンD：switch文**

```
  ├─◇─ switch: `変数`eの値で判定
  │  ├─case 値1→ 処理1
  │  ├─case 値2, 値3 → 処理2
  │  └─それ以外→処理3
```

```c
switch (変数) {
    case 値1:
        処理1;
        break;
    case 値2:
    case 値3:
        処理2;
        break;
    default:
        処理3;
        break;
}
```

#### 14.2 繰り返し（`↻`）

**パターンA：配列の全要素を順に処理**

```
└─↻─for:　ループ変数をi として、array の要素の数だけ繰り返す
    │
    └─　処理
```

```c
for (int i = 0; i < ARRAY_LEN(array); i++) {
    処理;
}
```

**パターンB：while（条件式に入力を含む形）**

```
└─↻─while: number にキーボードから整数を入力し、それが0 でない間繰り返す
    │
    └─処理
```

```c
while ((number = getInt(NULL)) != 0) {
    処理;
}
```

**パターンC：無限ループ + break（条件付き脱出）**

```
├─合計の計算─↻─ while: true
│              ├─処理1
│              ├─◇─終了条件
│              │        └─ breakでループを脱出する
│              └─処理2
```

```c
while (true) {
    処理1;
    if (終了条件) {
        break;
    }
    処理2;
}
```

`true` を使う場合は `#include <stdbool.h>` を補う。

**パターンD：通常のfor（カウンタ制御）**

```
└─↻─ for: i を0 からn 未満まで1 ずつ増やす
    │
    └─処理
```

```c
for (int i = 0; i < n; i++) {
    処理;
}
```
