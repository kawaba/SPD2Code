# SPDからのCコード生成スキル 作成・利用ガイド

構造化プログラム設計図（SPD：Structured Programming Diagram）を読み込ませ、C言語入門者向けのソースコードを生成するカスタムスキルを作成する方法を解説します。

SPDを貼らない依頼（コードの提案、要件定義からの仕様書作成）にも、同じスキルで対応します。どちらの使い方になるかは、入力にSPD記号（`│` `├─` `└─` `◇` `↻`）が含まれるかどうかで、AIが判定します。

---

## 1. スキルフォルダの構成

本スキルは、AIへの指示をまとめた指示書（`SKILL.md`）1つで構成されます。知識ファイルは使いません。
```text
SKILL.md          # 変換ルールと生成手順をすべて定義する指示書
```

### ファイルの役割
- **`SKILL.md`**:<br>
　SPDの未記入部分は生成しないという最優先ルール、全モード共通のルール（回答スタイル、コーディングスタイル、入出力、メモリとポインタ、エラー処理、利用できる外部ライブラリなど）、SPDモードのルール（記号一覧、読解の基本ルール、制御構造・構造体・列挙型・関数定義のパターン、`#include` とヘッダファイルの生成、チェックリスト）、通常モードのルール（提案時のテンプレート、仕様書のテンプレート）をまとめた台本です。

---

## 2. スキルの作成・登録手順

`SKILL.md` をAI環境に登録し、カスタムスキルとして保存します。

1. **AI環境へのアップロード**
   AIのチャット画面に、`SKILL.md` をドラッグ＆ドロップ（または添付）します。
2. **登録の指示**
   チャット欄に以下のように入力して実行します。
   > 「アップロードした `SKILL.md` を使って、SPDからCのコードを生成するスキルを作成・保存してください。」
3. **保存完了**
   AI側でシステムツールが実行され、いつでも呼び出し可能なカスタムスキルとして登録されます。
