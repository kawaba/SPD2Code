# SPD・要件定義からのPythonコード生成スキル 作成・利用ガイド

Python入門教育向けに、Pythonのソースコードを生成する2つのカスタムスキルを作成する方法を解説します。

- **SPDからのコード生成スキル**：構造化プログラム設計図（SPD：Structured Programming Diagram）を読み込ませ、初心者向けのPythonコードを生成します。
- **要件定義からのコード生成スキル**：自然文の要件定義（目的、入力、出力、処理条件、制約など）から仕様書を作成します。作成した仕様書からPythonコードも生成できます。

SPDからのコード生成スキルは、AIの「マルチファイル構成（指示書＋参考資料の組み合わせ）」を利用することで、変換ルールを正確に維持しながらコード生成を行えるのが特徴です。

---

## 1. スキルフォルダの構成

2つのスキルは、それぞれのフォルダに分けて置きます。どちらの指示書も `SKILL.md` という同じ名前だからです。
```text
spd-to-python-generator/            # SPDからのコード生成スキル
    SKILL.md                        # 全体の制御と変換ルールを定義する指示書
    spd-pattern-python-code.md      # SPDからPythonへの変換パターン集（知識ファイル）
requirements-to-python-generator/   # 要件定義からのコード生成スキル
    SKILL.md                        # 仕様書とコードの作り方を定義する指示書
```

### 各ファイルの役割
- **`spd-to-python-generator/SKILL.md`**:<br>
　SPDの読み方、Pythonへの変換原則、クラス定義、コーディング規約などを指示する中心的な台本です。SPDの未記入部分は生成しないという最優先ルールもここに定めています。
- **`spd-to-python-generator/spd-pattern-python-code.md`**:<br>
　SPDの記号（`◇`・`↻`・`〇` など）と生成するPythonの対応を示す変換パターン早見表、具体的なプログラムでの作成例、未記入SPDの適用例。生成方法に迷ったときにAIが参照します。
- **`requirements-to-python-generator/SKILL.md`**:<br>
　`main()` と実行エントリ、関数化の判断、仕様書のテンプレート、オブジェクト設計、エラーハンドリング、コーディング規約などを指示する台本です。このスキルは知識ファイルを使いません。

---

## 2. スキルの作成・登録手順

2つのスキルを1つずつ作成します。どちらの指示書も `SKILL.md` という名前なので、**スキルごとに新しいチャットを開いて**作成してください。1つのチャットに両方のファイルを添付すると、どちらの `SKILL.md` かをAIが区別できません。

### 2.1 SPDからのコード生成スキル

`spd-to-python-generator` フォルダの2つのファイルをAI環境に登録し、カスタムスキルとして保存します。

1. **AI環境へのアップロード**
   新しいチャットを開き、`SKILL.md` と `spd-pattern-python-code.md` を同時にドラッグ＆ドロップ（または添付）します。
2. **登録の指示**
   チャット欄に以下のように入力して実行します。
   > 「アップロードした `SKILL.md` と、知識である `spd-pattern-python-code.md` を使って、SPDからPythonのコードを生成するマルチファイル構成のスキルを作成・保存してください。」
3. **保存完了**
   AI側でシステムツールが実行され、いつでも呼び出し可能なカスタムスキルとして登録されます。

### 2.2 要件定義からのコード生成スキル

`requirements-to-python-generator` フォルダの `SKILL.md` をAI環境に登録し、カスタムスキルとして保存します。

1. **AI環境へのアップロード**
   新しいチャットを開き、`SKILL.md` をドラッグ＆ドロップ（または添付）します。
2. **登録の指示**
   チャット欄に以下のように入力して実行します。
   > 「アップロードした `SKILL.md` を使って、要件定義からPythonの仕様書とコードを生成するスキルを作成・保存してください。」
3. **保存完了**
   AI側でシステムツールが実行され、いつでも呼び出し可能なカスタムスキルとして登録されます。

## 3. スキルの利用方法

作成したスキルは、日常の学習・開発作業の中で次のように呼び出して利用できます。

### 3.1 SPDからのコード生成スキル

#### 基本的な使い方
チャットに、SPDのテキスト、または先頭のdocstringブロック（`"""` で囲んだブロック）にSPDを書いたPythonファイルを貼り付け（または添付し）、スキルを呼び出します。
`main` 用と関数用など、複数のSPDをまとめて貼り付けてもかまいません。

   > **プロンプト例：**<br>
   > 「（SPDを貼り付けた後、）このSPDをもとに、Pythonのソースコードを生成してください」<br>
   > 「（Pythonファイルを添付した後、）先頭のSPDをもとに、Pythonのソースコードを生成してください」

#### 期待される動作
1. AIが自動的に `SKILL.md` の指示と、`spd-pattern-python-code.md` の変換パターンを参照します。
2. SPDに未記入の部分（`★ここにSPD を書く★` の行や、中身の無い枝）があれば、その関数・メソッドは生成せず、コメント1行で知らせます。
3. SPDをファイル先頭のdocstringブロックに一字一句そのまま残し、その下に、規約に準拠した初心者向けのPythonコードを出力します。
4. 識別子の誤記や見つからない名前があれば、コードの後の「生成後の報告」で知らせます。

### 3.2 要件定義からのコード生成スキル

#### 基本的な使い方
チャットに、要件定義（目的、入力、出力、処理条件、制約など）を書いて、スキルを呼び出します。
まず仕様書を作り、その内容を確認してから、仕様書をもとにコードを生成する2段階の使い方をおすすめします。

   > **プロンプト例：**<br>
   > 「（要件定義を書いた後、）この要件定義から仕様書を作成してください」<br>
   > 「（仕様書を確認した後、）この仕様書をもとに、Pythonのソースコードを生成してください」

#### 期待される動作
1. AIが自動的に `SKILL.md` の指示を参照します。
2. 仕様書を作るときは、関数候補ごとに関数にするかどうかを判定してから、決まったテンプレート（概要／作成する関数の構成／入出力の仕様／処理の流れ／各関数の仕様／備考）で出力します。
3. コードを作るときは、`main()` 関数と実行エントリ（`if __name__ == "__main__":`）を持つ、初心者向けのPythonコードを出力します。指示されていない処理は追加しません。
