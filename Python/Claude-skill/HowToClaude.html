Claudeの"スキル"を使ってPythonコードを生成する方法

Python入門教育向けに、Pythonのソースコードを生成する2つのスキルを、Claude（ウェブ版の claude.ai）に登録して使う方法を解説します。

  • SPDからのコード生成スキル：構造化プログラム設計図（SPD：Structured Programming Diagram）を読み込ませ、初心者向けのPythonコードを生成します。
  • 要件定義からのコード生成スキル：自然文の要件定義（目的、入力、出力、処理条件、制約など）から仕様書を作成します。作成した仕様書からPythonコードも生成できます。

スキルは、無料プランでも使えます。登録する前に、下の「2. 準備」の設定をしてください。

1. スキルファイルの構成

スキルは、1つずつ zip ファイルにまとめてあります。次の2つをダウンロードしてください。SPD2Code-main.zip をダウンロードして解凍した場合は、その中の Python/Claude-skill フォルダにあります。

  • spd-to-python-generator.zip（SPDからのコード生成スキル）
  • requirements-to-python-generator.zip（要件定義からのコード生成スキル）

zip ファイルは解凍せずに、そのまま登録します。 zip の中身は次のとおりです。

spd-to-python-generator               # SPDからのコード生成スキル
├─SKILL.md                            # 全体の制御と変換ルールを定義する指示書
└─references                          # 変換パターン集（節ごとに分けたファイル）
    ├─1-…md                           # 変換パターン早見表（SPDの記号とPythonの対応）
    ├─2-…md                           # 作成例（具体的なプログラムでの変換例）
    ├─3-unfilled.md                   # 未記入SPDの適用例
    └─history.md                      # 更新履歴

requirements-to-python-generator      # 要件定義からのコード生成スキル
└─SKILL.md                            # 仕様書とコードの作り方を定義する指示書

各ファイルの役割

  • spd-to-python-generator/SKILL.md:
    　SPDの読み方、Pythonへの変換原則、クラス定義、コーディング規約などを指示する中心的な台本です。SPDの未記入部分は生成しないという最優先ルールもここに定めています。
  • spd-to-python-generator/references フォルダ:
    　SPDの記号（◇・↻・〇 など）と生成するPythonの対応を示す変換パターン早見表、具体的なプログラムでの作成例、未記入SPDの適用例を、節ごとのファイルに分けたものです。AIは、生成方法に迷ったときに必要なファイルだけを読みます。1回に読む量が少なくなるので、使用量の上限に達しにくくなります。
  • requirements-to-python-generator/SKILL.md:
    　main() と実行エントリ、関数化の判断、仕様書のテンプレート、オブジェクト設計、エラーハンドリング、コーディング規約などを指示する台本です。

2. 準備（最初に1回だけ）

スキルは「コード実行とファイル作成」の機能を使って動きます。この機能をオンにしておきます。

  1. claude.ai にログインし、左下のアカウント名から Settings（設定） を開きます。
  2. Capabilities（機能） を開き、Code execution and file creation（コード実行とファイル作成） をオンにします。

コードが崩れて表示されるとき（Edge）

生成されたコードの改行がつながったり、return が「帰還」、print が「印刷」のように変わって表示されたりする場合は、ブラウザーの翻訳機能がページを機械翻訳しています。コピーボタンでコピーしたコードは正しいので、コード自体には問題ありません。Edge では、次の手順で英語のページを自動で翻訳しないようにします。

  1. アドレスバーに edge://settings/languages と入力して開きます。
  2. 「常に翻訳する言語」などの一覧に「英語」（「英語 (米国)」なども）があれば、すべて削除します。

3. スキルの登録手順

2つのスキルを、1つずつ登録します。

  1. Customize（カスタマイズ） の Skills（スキル） を開きます。
  2. ＋ を押し、Create skill（スキルを作成） → Upload a skill（スキルをアップロード） を選びます。
  3. ダウンロードした spd-to-python-generator.zip を選びます。
  4. もう一度 1〜2 の手順を行い、requirements-to-python-generator.zip を選びます。
  5. スキルの一覧に spd-to-python-generator と requirements-to-python-generator が表示され、オンになっていれば登録完了です。

画面の項目名は、表示の言語や画面の変更によって、上と少し違うことがあります。片方のスキルだけを使う場合は、そのスキルだけを登録してもかまいません。

スキルを新しくするとき

変換ルールが新しくなったときは、一覧から古いスキルを削除してから、新しい zip を登録します。

4. スキルの利用方法

AIは、チャットの内容を見て、どちらのスキルを使うかを自動で選びます。SPDを貼り付けたときはSPDからのコード生成スキルを、文章で要件を書いたときは要件定義からのコード生成スキルを使います。確実に使わせたいときは、依頼文の中でスキルの名前を挙げます。

4.1 SPDからのコード生成

基本的な使い方

チャットに、SPDを貼り付け、コードを生成するように依頼します。 main 用とその他の関数用など、複数のSPDをまとめて貼り付けてもかまいません。

プロンプト例：
「（SPDを貼り付けた後、）このSPDをもとに、Pythonのソースコードを生成してください」
「（SPDを貼り付けた後、）spd-to-python-generator スキルを使って、このSPDからPythonのコードを生成してください」

期待される動作

  1. AIが SKILL.md の指示を読み、必要に応じて references フォルダの変換パターンを読みます。
  2. SPDに未記入の部分（★ここにSPD を書く★ の行や、中身の無い枝）があれば、その関数・メソッドは生成せず、コメント1行で知らせます。
  3. SPDをファイル先頭のdocstringブロックに一字一句そのまま残し、その下に、規約に準拠した初心者向けのPythonコードを出力します。
  4. 識別子の誤記や見つからない名前があれば、コードの後の「生成後の報告」で知らせます。

4.2 要件定義からのコード生成

基本的な使い方

チャットに、作成した要件定義（目的、入力、出力、処理条件、制約など）を貼り付け、仕様書の生成を依頼します。 仕様書が生成されたらその内容を確認し、次は、その仕様書をもとにコードを生成するように依頼します。

プロンプト例：
「（要件定義を書いた後、）この要件定義から仕様書を作成してください」
「（仕様書を確認した後、）この仕様書をもとに、Pythonのソースコードを生成してください」

期待される動作

  1. AIが SKILL.md の指示を読みます。
  2. 仕様書を作るときは、関数候補ごとに関数にするかどうかを判定してから、決まったテンプレート（概要／作成する関数の構成／入出力の仕様／処理の流れ／各関数の仕様／備考）で出力します。
  3. コードを作るときは、main() 関数と実行エントリ（if __name__ == "__main__":）を持つ、初心者向けのPythonコードを出力します。指示されていない処理は追加しません。

注意点

  1. 別ファイルに定義したクラスや関数を使う場合は、そのPythonファイルをチャット欄に先にアップロードしておきます。
  2. 無料プランでは、使用量に上限があります。1つの会話が長くなるほど使用量が増えるので、別の作業に移るときは新しいチャットを始め、必要なファイルをアップロードし直してください。
