Geminiの"スキル"を使ってJavaコードを生成する方法

構造化プログラム設計図（SPD：Structured Programming Diagram）を読み込ませ、Javaのソースコードを生成するカスタムスキルを作成する方法を解説します。

このスキルは、AIの「マルチファイル構成（指示書＋参考資料の組み合わせ）」を利用することで、複雑な変換ルールやプロジェクトの仕様を正確に維持しながらコード生成を行えるのが特徴です。

1. スキルフォルダの構成

本スキルは、AIへの指示をまとめたメインの指示書（SKILL.md）と、変換ルールや設定を記述した知識ファイルで構成されます。

SKILL.md          # 全体の制御と変換ワークフローを定義する指示書
ガイドライン.txt  # SPD記述ルールとJava変換ルール
pom.xml           # プロジェクトの依存関係・設定ファイル

各ファイルの役割

  • SKILL.md:
    　AIがいつ・どのようにこのスキルを起動し、どの順番でファイルを参照してコードを生成すべきかを指示する中心的な台本です。SPDの未記入部分は生成しないという最優先ルール、記号一覧、SPDの読み方、生成時のチェックリストもここにあります。
  • ガイドライン.txt:
    　SPDの要素（順次、選択、繰り返し、例外処理、ラムダ式、ストリーム処理など）の読み方、クラス定義、キーボード入力（Input）、四捨五入（Tools.round）など、Javaへの変換ルールの全文。
  • pom.xml:
    　利用するライブラリのバージョン情報をAIに正しく認識させるための設定ファイル。AIは、import文を生成するときにこのファイルを参照します。

2. スキルの作成・登録手順

3つのファイルをAI環境に登録し、カスタムスキルとして保存します。

  1. AI環境へのアップロード AIのチャット画面に、すべてのファイルを同時にドラッグ＆ドロップ（または添付）します。
  2. 登録の指示 チャット欄に以下のように入力して実行します。

    「アップロードした SKILL.md と、知識であるそれ以外の2つのファイルを使って、SPDからJavaのコードを生成するマルチファイル構成のスキルを作成・保存してください。」

  3. 保存完了 AI側でシステムツールが実行され、いつでも呼び出し可能なカスタムスキルとして登録されます。

3. スキルの利用方法

作成したスキルは、日常の学習・開発作業の中で次のように呼び出して利用できます。

基本的な使い方

チャットに、SPDのテキスト、または先頭のブロックコメント（/* ... */）にSPDを書いたJavaファイルを貼り付け（または添付し）、スキルを呼び出します。 クラス用とメソッド用など、複数のSPDをまとめて貼り付けてもかまいません。

プロンプト例：
「（SPDを貼り付けた後、）このSPDをもとに、Javaのソースコードを生成してください」
「（Javaファイルを添付した後、）先頭のSPDをもとに、Javaのソースコードを生成してください」

期待される動作

  1. AIが自動的に SKILL.md の指示を読み、SPDに現れる記号や型定義に応じて、ガイドライン.txt の該当する節を参照します。
  2. コードを書く前に、未記入判定: の1行（◇ が複数あれば ◇判定: の1行も）を出力します。SPDに未記入の部分があれば、そのメソッドやクラスは生成せず、コメント1行で知らせます。
  3. pom.xml の依存ライブラリに合わせてimport文を選びます。キーボード入力には jp.kwebs.tools.Input、桁数を指定した四捨五入には Tools.round を使い、package 文は書きません。
  4. SPDを1つのブロックコメントにまとめてファイルの冒頭に残し、その下に規約に準拠したJavaコードを出力します。識別子の誤記や見つからない名前があれば、コードの後の「生成後の報告」で知らせます。

注意点

  1. 一回に1つのSPDから1つのコードを生成してください。
  2. ただし、コード生成に必要な他のJavaファイル（クラスやインタフェースの定義など）がある場合は、チャット欄でそれらをアップロードしておいてください。
