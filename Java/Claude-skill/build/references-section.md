# references の構成

詳細な規約は、`references/` フォルダーに節ごとのファイルで置いてある。**必要な節のファイルだけを開いて読む。** フォルダーのファイルをまとめて読んだり、関係のないファイルを開いたりしない。

**ファイルを読んでいる間は、何も書かない。** 「規約を読み込んでいます」「〜を確認してから生成します」のような途中経過や予告を出力しない。出力は、必要なファイルをすべて読み終えてから、`未記入判定:` の1行で始める。出力してよいのは `## 0.5` の6つだけである。

- 規約の中で `## 9.6` のように節番号だけで参照しているときは、下の表でその番号のファイルを開く。`## 0.8`・`## 9.6.4` のような下位の節は、上位の節（`## 0`・`## 9.6`）のファイルにある。
- `## 9.4` は、記号ごとに5つのファイルに分けてある（分岐 `◇`・繰り返し `↻`・例外処理 `〇`・ラムダ式 `λ`・ストリーム処理 `▽`）。SPDに現れる記号のファイルだけを開く。ストリーム処理の中にラムダ式があるときは、両方を開く。
- 「最重要ルール」と `## 1`〜`## 3`・`## 6`〜`## 8` は `references/01-general.md` にある。
- `## 9.2`・`## 9.3`・`## 9.9` は、この `SKILL.md` に全文がある。references のファイルを開く必要はない。
- `references/pom.xml` は依存ライブラリの見本である。チャットに `pom.xml` が添付された場合は、そちらを優先する。
- 規約は GitHub Copilot 用の規約から作っているため、「ワークスペース」は、チャットに貼られたSPD、チャットに添付されたファイル、同じ会話でそれまでに出力したコードと読み替える。
