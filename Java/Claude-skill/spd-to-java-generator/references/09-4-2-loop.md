#### 繰り返し（`↻`）

##### パターンA：拡張for（コレクションの全要素を順に処理）
```
└─ ↻─ for: 変数nにlistから毎回１つずつ要素を取り出す
      └─ 処理
```

```java
for (var n : list) {
    処理;
}
```

##### パターンB：while（条件式に副作用を含む形）
```
└─ ↻─ while: numberにキーボードから整数を入力し、それが0でない間繰り返す
        └─ 処理
```

```java
while ((number = Input.getInt()) != 0) {
    処理;
}
```

##### パターンC：無限ループ + break（条件付き脱出）
```
├─ 合計の計算─ ↻─ while: true
│                 ├─ 処理1
│                 ├─ ◇─終了条件
│                 │   └─ breakでループを脱出する
│                 └─ 処理2
```

```java
while (true) {
    処理1;
    if (終了条件) {
        break;
    }
    処理2;
}
```

##### パターンD：通常のfor（カウンタ制御）

明示的にカウンタ範囲が示される場合：
```
└─ ↻─ for: iを0からn未満まで1ずつ増やす
      └─ 処理
```

```java
for (int i = 0; i < n; i++) {
    処理;
}
```
