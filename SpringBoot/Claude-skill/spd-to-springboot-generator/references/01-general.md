## 最重要ルール（最初に確認）
- **`## 0.` の規則（SPDの未記入部分は生成しない）を、他のすべての規則に優先して適用すること。**
- 実装前に、`SKILL.md` の対応表で該当する節を特定し、そのファイルを確認してからコード生成・修正を行うこと（規約のファイルをすべて読む必要はない）。
- **コード生成時、提供されたSPD（設計図）は消さずに、ファイルの先頭に、そのまま残すこと。**
- **SPDからコードを生成する場合は、まずSPD全体をそのままブロックコメント（`/* ... */`）としてソースコードの冒頭（`import` 文の後・型定義の直前）に残し、その下に生成したコードを書くこと。SPDを消してコードだけにしてはならない。**
- **SPDを細切れに分割して、コードの前に小出しに書き込まないこと。**
- **小数点以下の桁数を指定して四捨五入する場合**は、必ず `jp.kwebs.tools.Tools.round` を使用すること。
- **整数へ四捨五入する場合**（小数点以下0桁）は、`Math.round()` を使用すること。
- `Tools.round` の代わりに `Math.round`・`BigDecimal`・`String.format` による丸めを使わないこと。
- SPD記法の設計図からコード生成する場合は、共通規約（`references/` の `00`〜`11` で始まるファイル）を確認すること。
- **Web層（コントローラー・サービス・リポジトリ・エンティティ）を生成する場合は、Spring Boot 規約（`references/20-*.md`）を確認すること。**
- **Thymeleafテンプレートを生成する場合は、Thymeleaf 規約（`references/30-*.md`）を確認すること。**
- **コードを書き始める前に、`未記入判定: 名前=記入済み 名前=未記入 …` の1行を出力すること**（`## 0.3.6`）。次の `◇判定:` の1行も出す場合は、`未記入判定:` を先、`◇判定:` を後にする。
- **SPDに `◇` が複数ある場合は、コードを書き始める前に、次の形式の1行だけを出力し、その直後にコードを生成すること。**
    - 形式：`◇判定: 1=if 2=elif 3=if …`（`◇` の出現順に通し番号を付け、`if` か `elif`（＝直上への `else if` 連結）かだけを並べる）
    - **この1行以外は出力しない。** 表・箇条書き・SPD行の引用・判定理由の説明を書いてはならない。
    - 分類は `## 9.4` の文字テスト（`◇` の左の最初の非空白文字が `│`／行頭なら `else if`、それ以外はすべて新しい `if`）だけで行い、桁位置は判定に使わない。この1行を確定させてからコードを生成する。SPDが長いほどこの手順を省略しない。

## 3. Java コーディング方針
- 既存パッケージ構成に従う（例: `com.example.app.controller` / `.service` / `.repository` / `.entity` / `.form`）。
- 既存命名規則（クラス名、メソッド名、変数名）を優先する。
- 例外処理は握りつぶさず、必要に応じてメッセージを残す。
- 文字コードは既存設定に合わせる（不明な場合は UTF-8 を前提に確認する）。
- ローカル変数の宣言で、右辺がオブジェクトを返す式（`new` によるインスタンス生成、ファクトリメソッド、キャスト式など）の場合は、型名に `var` を積極的に使用すること。
  - ただし、配列を宣言と同時に要素で初期化する場合（`{ ... }` 初期化子）は `var` を使わず、明示的な配列型で宣言すること。
  - 上記の配列即時初期化では `new` を使わないこと（例: `String[] fruits = { "apple", "banana", "orange" };`）。

  ```java
  // 推奨
  var list  = new ArrayList<String>();   // new によるインスタンス生成
  var names = List.of("Alice", "Bob");   // ファクトリメソッド
  var map   = Map.of("key", 123);        // ファクトリメソッド
  var sb    = new StringBuilder();
  String[] fruits = { "apple", "banana", "orange" }; // 配列の即時初期化は明示型

  // 非推奨（型が冗長 or プロジェクト方針に非準拠）
  ArrayList<String> list = new ArrayList<String>();
  List<String> names = List.of("Alice", "Bob");
  var fruits = new String[] { "apple", "banana", "orange" };
  ```

- 繰り返し処理のfor文では、デフォルトで**拡張for文**（for-each）を使用すること。
  - インデックスが必要な場合（例: 要素の位置を使う、逆順、飛ばし処理）に限り、通常のインデックスfor文を使用すること。
  - 明示的に「インデックスfor文を使う」と指示された場合も同様に許可する。

  ```java
  // 推奨（拡張for文）
  for (String name : names) {
      System.out.println(name);
  }

  // インデックスが必要な場合のみ許可
  for (int i = 0; i < names.length; i++) {
      System.out.println(i + ": " + names[i]);
  }
  ```

## 5. 四捨五入（丸め処理）

- **小数点以下の桁数を指定して四捨五入する場合**は、`jp.kwebs.tools.Tools` クラスの `round` メソッドを使用すること。
- **整数へ四捨五入する場合**（小数点以下0桁）は、標準クラスの `Math.round()` を使用すること。
- `Tools.round` の代わりに `Math.round`・`BigDecimal`・`String.format` による丸めを使わないこと。

### インポート

```java
import jp.kwebs.tools.Tools;
```

### メソッドシグネチャ

```java
// value を小数点以下 digits 桁で四捨五入して返す
static double Tools.round(double value, int digits)
```

### 使用例

```java
import jp.kwebs.tools.Tools;

// 小数点以下2桁に四捨五入
double result = Tools.round(3.14159, 2);  // → 3.14

// 小数点以下1桁に四捨五入
double tax = Tools.round(price * 0.1, 1);

// 整数への四捨五入は標準クラスを使う
long rounded = Math.round(3.7);       // → 4
int n        = (int) Math.round(3.7); // → 4
```
