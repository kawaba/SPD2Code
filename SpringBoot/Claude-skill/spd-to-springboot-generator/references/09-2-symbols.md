### 9.2 記号一覧

#### 構造記号

| 記号 | 意味 |
|---|---|
| `│` | 縦方向の処理の流れ |
| `├─` | 兄弟処理の項目（同じレベルにまだ続きがある） |
| `└─` | 兄弟処理の最後の項目、または上位項目の**詳細・補足** |
| `※` | 1行コメント（`※` からその行末までがコメント。`## 9.3` ルール6） |
| `←` / `=` | 代入（`変数←値`／`変数=値`。ともに同じ意味。`自動生成` ノード内の `←` だけは対象フィールド指定、`## 9.6.4`） |

#### 制御構造記号

| 記号 | 意味 | 対応するJava構文 |
|---|---|---|
| `◇` | 分岐 | `if` / `else if` / `else` / `switch` |
| `↻` | 繰り返し | `for` / `while` / 拡張for |
| `〇` | 例外処理ブロック | `try` / `catch` / `finally` |
| `┬` | ブロック開始 | 1つの分岐・case内、またはラムダ式（`## 9.4`）の本体で複数処理を行うまとまり |
| `λ(引数並び)：` | ラムダ式 | `->`（`## 9.4`） |
| `▽─stream:（コレクション）`／`▽─（式）` | ストリーム処理 | `（コレクション）.stream()…` ／ 書かれた式をそのままストリーム源にする（`Files.lines(path)…`。`## 9.4`） |

#### 型定義の記号

| 記号 | 意味 |
|---|---|
| `+` `#` `~` `-` | アクセス修飾子：public / protected / package(無修飾) / private |
| `─⊳` | 継承（extends） |
| `---⊳` | 実装（implements） |
| `← 変数並び` | 等値判定/ゲッター/セッター/移譲メソッドの対象フィールド指定 |

例：`クラス: StudentMember ─⊳ Member ---⊳ Versionable`
→ `public class StudentMember extends Member implements Versionable`

- `─⊳`・`---⊳` の後には、**複数の型を読点（`、`）または `,` で区切って並べてよい**。型引数も書ける。
  例：`クラス: Member ---⊳ Versionable, Comparable<Member>`
  → `public class Member implements Versionable, Comparable<Member>`
- **インタフェースの継承には `─⊳` を使う**（Java の `extends` に対応する。`## 9.5.2`）。
- 次の場合は不整合として指摘する。
  - `クラス`・`抽象クラス` の `─⊳` に型が2つ以上書かれている（Java は単一継承である）
  - `インタフェース` に `---⊳` が書かれている（インタフェースは `implements` できない。継承なら `─⊳` を使う）
  - `レコード` に `─⊳` が書かれている（レコードは継承できない。インタフェースの実装 `---⊳` は書ける）

型定義のタイトルに書けるノード名は `クラス`／`抽象クラス`／`インタフェース`／`レコード` の4種類である。

例：`抽象クラス：Member` → `public abstract class Member`（`## 9.5.4`）

修飾子を省略したときの既定値は文脈で異なる（**クラス・クラス変数・メソッド＝`+`(public)／フィールド＝`-`(private)**）。
`クラス:` `メソッド:` などのノード名のコロンは、全角（`：`）・半角（`:`）の**どちらでもよい**（両者を区別しない）。

#### ノード名の別名（同義語）

次の表記は同じ意味として扱い、**黙って読み替える**（指摘や警告は出さない）。

| 正式表記 | 同義として受理する旧表記 |
|---|---|
| `フィールド` | `属性` |
| `自動生成` | `自動生成のリスト`／`自動生成のパターン` |
| `インスタンスメソッド` | `メソッド` |
| `コンストラクタ`（ノード） | `コンストラクタ：オーバーロード` |
| `クラスメソッド` | `スタティックメソッド`／`静的メソッド` |
| `等値判定` | `equals`／`hashCode`（`## 9.6.4`） |
| `コンストラクタ：全引数` | `コンストラクタ`（`自動生成` の中に種別なしで書かれた場合） |
