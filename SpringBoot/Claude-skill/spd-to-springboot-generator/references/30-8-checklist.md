## 30.8 生成時のチェックリスト（Thymeleaf）

- [ ] テンプレートを `templates/<テンプレート名>.html` に生成したか。テンプレート名をそのまま使ったか（`## 11.1`）
- [ ] 規約に無い書き方（v7 までの `［一覧］`、v6 までの `［条件表示］`・`［そうでなければ］`、v5 までの `見出し：…`・`表＜列定義＞`・`［…］` の書式、それより前の `⇒`・`ボタン：` など）を読み替えずに、生成せず報告したか（`## 30.1`）
- [ ] `［…］` で始まる行だけをノードとして読んだか。`［…］` も `：` も `＜…＞` も無い行、表とフォームの外の `ラベル：値`、表に無いノードの種類を報告したか（`## 30.1`・`## 30.3`）
- [ ] `ラベル：値` を表示、`＜種類＞` の付いた項目を入力として生成したか。フォームの中の `ラベル：{…}` を入力欄にしていないか。フォームの中の、値がフィールド名の形の `ラベル：値`（`名前：name`）を推測で生成せず報告したか。フォームの外の入力項目・ボタンを報告したか（`## 30.1`・`## 30.5`）
- [ ] 値の `{…}` だけを変数として `th:text` で出力し、`{…}` の無い値は本文にそのまま書いたか。文字と変数が混ざった値を `|…|` で生成したか。ラベルの `{…}`・全角の `｛…｝` を報告したか（`## 30.1`・`## 30.3`）
- [ ] 値の位置のノードを `［画像］`・`［リンク］`・`［文字］`・`［通知］` だけにしたか。文字と混ぜた `［…］`、値と子の両方がある行・列を報告したか（`## 30.3`〜`## 30.5`）
- [ ] 子に並べた `［段落］` を、子を間に空白も改行も入れずに続けた1つの `<p>` にしたか。子が `［文字］`・`［リンク］`・`［画像］`・`［改行］` だけであるか。値と子の両方がある・値も子も無い `［段落］` を報告したか。`［改行］` を、要素を並べる場所（`［段落］` の子・マスの子・`┬`）にだけ `<br>` で生成したか（`## 30.3`）
- [ ] `受け取り` の名前と、コントローラーの「〜をテンプレートに渡す」の名前が一致しているか。型を生成に使っていないか（`## 11.2`・`## 30.2`）
- [ ] `css` を `<head>` に `th:href="@{…}"` で読み込んだか。レイアウトを使う画面では生成せずに報告したか（`## 30.2`）
- [ ] 静的な文字列に `th:text` を付けていないか。`th:text` にプレビュー用のダミーを残したか。ダミーを、受け取りの名前そのものなら受け取りのラベル、`ラベル：{…}` ならそのラベル、それ以外は式の最後の名前で決めたか。見本の値（`2026年01月01日`・`1,000`）を作っていないか（`## 30.3`）
- [ ] すべてのパスを `@{…}` で囲んだか。素の `href`／`action` を書いていないか（`## 30.3`）
- [ ] パス変数を `{名前}` + `(名前=${式})` の形にしたか。文字列連結にしていないか（`## 30.3`）
- [ ] リンク・フォームのパスが、コントローラーの `ベースパス` ＋ `マッピング` と一致しているか（`## 11.4`）
- [ ] `［表（列）］` に「各要素」の句があり、`［表（行）］` に無いことを確かめたか。`th:each` を `<tr>`／`<li>` に付けたか（`## 30.4`・`## 30.5`）
- [ ] 値の書式を表のとおりに生成し、`null` のとき空欄にしたか。表に無い書式（`通貨表示` など）を推測で作っていないか（`## 30.4`）
- [ ] 入力項目・`［リンク］`・`［画像］`・`┬` の行・ボタンに書かれた書式を報告したか。フォームの中でフォームオブジェクトのフィールドに付けた書式を、`*{…}` の中に式全体を書いて生成したか（`## 30.4`）
- [ ] 型が分かるとき、書式と型が合うかを確かめたか（日付・時刻のパターンは `java.time` の型と時刻・日付の文字、`3桁区切り`・`円表示` は整数、連結は `List`・`Set`・配列で式を使い分ける）。合わないものを報告したか（`## 30.4`）
- [ ] パターンの `YYYY`・`D`、時の文字が無いパターンの `mm` を、生成したうえで報告したか。全角の引用符を `'…'` にしたか。パターンや区切りの中の `'`・`"` を報告したか（`## 30.4`）
- [ ] 書式を、`{…}` が1つだけの値にだけ付けたか。`<<…>>` の `.<クラス名>` を、`{…}` を含む値の要素と `<img>`・`<a>` に `class` として付けたか。`style` 属性にしていないか。それ以外の項目のクラス名を報告したか（`## 30.4`）
- [ ] `［画像］` を `th:src="@{…}"` で生成したか。`/` で始まらないパス・外部のURL・順序の違う書き方・`px` の無いサイズを報告したか。サイズを `width` 属性にしたか。代替文字列が無いときに `alt=""` を付けたか（`## 30.3`）
- [ ] 表（行）で、`：` がある行を2マス（ラベルか値が無ければ空の `<td>`）、`：` が無い `［ノード］` の行と、フォームの中のボタンを1つだけ書いた行を `colspan="2"` の1マスにしたか。表（列）の `：` の無い列を報告したか（`## 30.4`・`## 30.5`）
- [ ] 子に並べた列・行の子と、1マスの行が、書けるノードだけであることを確かめたか。ボタンを子に置いたのが、フォームの中の表（行）だけであるか（`## 30.4`・`## 30.5`）
- [ ] `［空］：` を `：` と同じ（左のマス・列見出しが空）に生成したか。`：` の左以外の `［空］` を報告したか。`┬` でまとめた要素を、書かれた順に1つの `<td colspan="2">` に置き、`┬` の行の `<<.クラス名>>` をその `<td>` に付けたか。表（行）以外の `┬` を報告したか（`## 30.1`・`## 30.5`）
- [ ] 行の先頭・値の先頭の `{…}` を含む `(…)` を条件として読んだか。`{…}` を含まない括弧と、値の途中の括弧を文字のままにしたか（`## 30.4`）
- [ ] 条件の `th:if` を、付いたものに合わせて付けたか（値だけはマスの中の `<span>`、表（行）の行頭は `<tr>`、フォームの直下の項目は `<div>`、ノードはその要素、`(条件)` だけの行は `<th:block>`）。`<td>` に付けていないか。`th:unless` を生成していないか（`## 30.4`）
- [ ] 条件を除くと正しくない行（`({flag}) 在庫あり` など）、表（列）の列の行頭の条件、表（列）の列と `［箇条書き］` の子の `(条件)` だけの行、子の無い `(条件)` だけの行、値の無い `ラベル：` とフィールド名に付けた条件を報告したか（`## 30.4`）
- [ ] 条件の言い方を表（表記の揺れを含む）のとおりに式にし、`gt`・`lt`・`ge`・`le`・`and`・`or`・`not` で1つの `${…}`（フォームのフィールドだけなら `*{…}`）に生成したか。表に無い言い方、`かつ` と `または` を混ぜた条件、計算・件数・メソッド呼び出し、引用符を含む文字列を報告したか（`## 30.4`）
- [ ] 「空」の式を型（`String`・`List`・`Set`・`Map`・配列）で決めたか。型が分からないものを `#strings` で生成して報告したか。`boolean` でないと分かる変数の `true`／`false` の条件を報告したか（`## 30.4`）
- [ ] 条件で消える入力項目のフィールドに `必須` があるとき、生成したうえで報告したか。`※任意` の受け取りを条件なしで使っているときに報告したか（`## 30.2`・`## 30.4`）
- [ ] `th:object` の中で、フォームオブジェクトのフィールド（SPD の `{memberForm.…}`）に `*{…}` を使ったか。`${memberForm.…}` と書いていないか。フォームオブジェクト以外の値を `*{…}` にしていないか（`## 30.3`・`## 30.5`）
- [ ] `th:field` があるのに `id`／`name`／`value` を手で書いていないか（選択肢の `value` を除く）（`## 30.5`）
- [ ] `th:object` のフォームの、`＜hidden＞` 以外のすべての入力項目に、`class="error-msg"` のエラー表示を付けたか（`## 30.5`）
- [ ] オブジェクト名を省略したフォームの入力項目に、`id`・`name` を手で書いたか。初期値・エラー表示・`th:field` を付けていないか。`＜hidden＞` を生成せずに報告したか（`## 30.5`）
- [ ] 選択肢を `表示名：値` から生成し、`<label>` で入力を包んだか（`## 30.5`）
- [ ] リストから作る選択肢を、「〜の各要素を〜とする」の下の `{表示名の式}：{値の式}` から `th:each` で生成したか。リストの名前が `受け取り` にあるか。`＜select＞` にだけ「選択してください」を付けたか（`## 30.5`）
- [ ] ボタンを `キャプション＜submit＞`・`＜reset＞` から `<button>` で生成したか（`## 30.5`）
- [ ] フォームを入れ子にしていないか。フォームの外にボタンを置いていないか（`## 30.1`・`## 30.5`）
- [ ] `th:utext` を生成していないか（`## 30.7`）
- [ ] 存在しないレイアウトを勝手に作っていないか（`## 30.6`）
- [ ] `構成` に無い要素・CSSクラス・JavaScriptを追加していないか（`## 30.7`）
- [ ] `xmlns:th`・`lang="ja"`・`<meta charset="UTF-8">`・`<meta name="viewport" …>` を入れたか（`## 30.7`）
- [ ] テンプレートSPD全体を `<!--/* … */-->` で冒頭に残したか（`## 30.7`）
